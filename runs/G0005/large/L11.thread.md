### How to use this as a refactor oracle

Run the five `#local` methods plus the two `TimeWithZone.new(nil, ...)` methods before and after. Any conversion change that only updates `#local` must still pass the TimeWithZone-constructed spring/fall cases, and vice versa.

```bash
cd activesupport && bin/test test/time_zone_test.rb -i "/test_local$|test_local_with_old_date|test_local_enforces_spring_dst_rules|test_local_enforces_fall_dst_rules|test_local_with_ambiguous_time|test_period_for_local_with_ambiguous_time/"

```

That first command is what I ran (6 tests, 22 assertions, pass). Gaps a conversion refactor can still slip through: Hawaii UTC/HST/`dst?`, Moscow `#time`/`MSK`/`dst?`, and 1850 LMT vs HST. Those are the extra assertions above; they are not in the suite today.
