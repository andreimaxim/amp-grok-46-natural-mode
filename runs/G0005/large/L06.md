`Array.wrap` is a three-way branch. It never special-cases `Array` or `Hash`. It never calls `to_a`.

```39:47:activesupport/lib/active_support/core_ext/array/wrap.rb
  def self.wrap(object)
    if object.nil?
      []
    elsif object.respond_to?(:to_ary)
      object.to_ary || [object]
    else
      [object]
    end
  end
```

### Contrast with `Kernel#Array` (from the method docs only)

The comment in [wrap.rb:16-29](file:///home/user/workspace/repo/activesupport/lib/active_support/core_ext/array/wrap.rb#L16-L29) states three differences:

- If `to_ary` returns `nil`, `Kernel#Array` continues to `to_a`; `Array.wrap` stops and returns `[object]`.
- If `to_ary` returns something that is neither `nil` nor an `Array`, `Kernel#Array` raises; `Array.wrap` returns that value.
- `Array.wrap` never calls `to_a`. If there is no `to_ary`, the object is wrapped as a single element. The Hash example is the documented illustration: `Array(foo: :bar) # => [[:foo, :bar]]` versus `Array.wrap(foo: :bar) # => [{:foo=>:bar}]`.

Nothing else about `Kernel#Array` is claimed in this source.
