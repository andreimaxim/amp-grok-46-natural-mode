**Why the keyword default does not make the line redundant**

```150:157:activesupport/lib/active_support/inflector/transliterate.rb
    def parameterize(string, separator: "-", preserve_case: false, locale: nil)
      separator ||= ""

      # Replace accented chars with their ASCII equivalents.
      parameterized_string = transliterate(string, locale: locale)

      # Turn unwanted chars into the separator.
      parameterized_string.gsub!(/[^a-z0-9\-_]+/i, separator)
```

Omitted `separator` is `"-"`. Explicit `separator: nil` is still `nil`. The RDoc already states that:

```123:128:activesupport/lib/active_support/inflector/transliterate.rb

    # empty separator. `nil` is treated the same way.

    # parameterize("Donald E. Knuth", separator: '') # => "donaldeknuth"
```

[`String#parameterize`](file:///home/user/workspace/repo/activesupport/lib/active_support/core_ext/string/inflections.rb#L242-L244) forwards `separator:` unchanged, so the Inflector change is the whole contract.

**Regression scope**

Not in scope of this deletion: single-character squeeze (`separator.length == 1`), multi-character collapse (`gsub!(/#{re_sep}{2,}/, ...)`), or `preserve_case` on non-nil separators. Those never hit `separator ||= ""`. `preserve_case` only matters on the nil path because existing tests pair `separator: nil` with both case modes; the TypeError happens before `downcase!`.
