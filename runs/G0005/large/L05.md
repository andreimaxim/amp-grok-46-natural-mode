`Array#excluding` (aliased as `without`) returns a new array of the receiver minus the given values: `self - elements.flatten(1)`. Arguments are flattened one level only, so `excluding(2, 3)` and `excluding([2, 3])` are the same, while a nested array is excluded as a single element only if you pass it wrapped (`excluding([[1, 0]])` drops `[1, 0]`; `excluding([1, 0])` looks for the scalars `1` and `0`). Every matching occurrence is removed; leftover duplicates stay. The receiver is not mutated.
