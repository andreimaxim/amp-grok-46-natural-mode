# Deterministic verification for `String#truncate_bytes`

Do not treat the refactor as the oracle. Pin fixtures, compute expected results from the **current** contract in [`filters.rb`](activesupport/lib/active_support/core_ext/string/filters.rb), then assert exact outputs.

Contract: `omission ||= ""`; if `bytesize <= truncate_to` then `dup`; if omission is larger then `ArgumentError`; if omission equals the budget then `omission.dup`; else walk `each_grapheme_cluster` into `self.class.new.force_encoding(encoding)` and append the omission.

Existing tests in `string_ext_test.rb` are necessary but not sufficient (no ASCII, combining marks, subclass, mutation, or equal-vs-larger omission). Run:

```bash
cd activesupport && bin/test test/core_ext/string_ext_test.rb -n "/truncate_bytes|truncates_bytes/"
```

Then add a table-driven check that, for every row, asserts value, `bytesize <= truncate_to`, encoding, `valid_encoding?`, class, distinct `object_id` from receiver and omission, and an unmutated snapshot. On error, assert `ArgumentError` plus the exact message.

**Fixtures:** `"Hello World!"` (12), `"👍👍👍👍"` (16), `"xx€yy"` (7), `"e\u0301e\u0301e\u0301"` (9), `"a ❤️ b"` (10), `"👩‍❤️‍👩"` (20), `"🇺🇸"` (8), `"…"` (3), `"🖖"` (4).

### What each observation proves

**Within-budget** (`"Hello World!".truncate_bytes(12)` and `(13)`, thumbs at 16, `"".truncate_bytes(0)`): returns a copy of the whole receiver; omission is unused. Returning `self` or always appending an omission fails here.

**ASCII** (`truncate_bytes(11)` → `"Hello Wo…"`, `(5)` → `"He…"`, `(3)` → `"…"`): budget is bytes, not `length`.

**Multibyte / exact boundaries** (`"xx€yy"` at 7/6/5/4 with `omission: nil` → full / `"xx€y"` / `"xx€"` / `"xx"`; thumbs at 16 vs 15 vs 9): never splits a UTF-8 codepoint; exact-fit vs one-byte-short catches off-by-one in `cut_at`. Result must stay `valid_encoding?`.

**Graphemes:** NFD `"ééé"` at 6 → `"éé"`, at 2 → `""` (not `"e"`). Heart at 7 → `"a "`, at 8 → `"a ❤️"`. Couple at 13 → `""`. Flag at 7 → `""`. Proves cluster cuts, not codepoints. NFD at 2 is the discriminating case against `each_char`.

**Custom / nil omission** on thumbs at 15/5/4: `nil` is empty suffix, not default `"…"`. Custom omission bytesize shrinks `cut_at`.

**Omission == budget** (`truncate_bytes(3)` → `"…"`, thumbs at 4 with `"🖖"` → `"🖖"`, `"abc".truncate_bytes(3, omission: "xyz")` → `"xyz"`) vs **larger** (`thumbs.truncate_bytes(3, omission: "🖖")` raises `Omission "🖖" is 4, larger than the truncation length of 3 bytes`). Equal and larger are different branches; result is `omission.dup`, not the omission object.

**Encoding / subclass:** UTF-8 in, valid UTF-8 out. `FancyString` is preserved on `dup` and cut paths, **not** on `omission.dup` (`truncate_bytes(3)` returns `String`). “Always `self.class.new`” is a behavior change.

**Mutation:** snapshot equality before/after, including after `FrozenError`-free calls and after `result << "x"`. Never returns `self` or the omission object.

The refactor is behavior-preserving iff existing focused tests stay green, every table row matches value/bytesize/encoding/class/identity, oversize omissions raise with the **current** message, and no receiver changes.
