## 2. ASCII truncation and exact byte boundaries

Receiver `"abcdef"` is 6 bytes. Default omission is 3 bytes.

| # | call | value | bytesize | encoding | class |
|---|------|-------|----------|----------|-------|
| 12 | `"abcdef".truncate_bytes(6)` | `"abcdef"` | 6 | UTF-8 | String |
| 13 | `"abcdef".truncate_bytes(5)` | `"ab…"` | 5 | UTF-8 | String |
| 14 | `"abcdef".truncate_bytes(5, omission: nil)` | `"abcde"` | 5 | UTF-8 | String |
| 15 | `"abcdef".truncate_bytes(5, omission: ".")` | `"abcd."` | 5 | UTF-8 | String |
| 16 | `"Hello World".truncate_bytes(8)` | `"Hello…"` | 8 | UTF-8 | String |
| 17 | `"Hello World".truncate_bytes(8, omission: "...")` | `"Hello..."` | 8 | UTF-8 | String |
| 18 | `"Hello World".truncate_bytes(8, omission: nil)` | `"Hello Wo"` | 8 | UTF-8 | String |

**What this proves:**
- Exact fit (row 12) takes the `dup` arm, not the cut arm.
- One-byte-short with default ellipsis (row 13) leaves `cut_at = 2`, so `"ab" + "…"`.
- `omission: nil` is empty, so the cut can use the full budget (row 14, 18).
- Custom 1-byte omission fills the last byte (row 15).
- Result bytesize is always `<= truncate_to`.

| 58 | `"hello".truncate_bytes(0, omission: nil)` | value `""`, bytesize 0, UTF-8, String, not identical |
| 59 | `"hello".truncate_bytes(0, omission: "")` | value `""`, bytesize 0, UTF-8, String, not identical to receiver or to the `""` literal |

Identity/mutation for row 53:

```ruby
om = "..."
s  = "Hello World"
r  = s.truncate_bytes(3, omission: om)
assert_equal false, r.equal?(om)
om << "X"
assert_equal "...", r          # result is omission.dup
assert_equal "Hello World", s
r << "Y"
assert_equal "...Y", r
assert_equal "...X", om
```

**What this proves:**
- `omission.bytesize == truncate_to` returns `omission.dup` (new object, unfrozen even if omission was frozen).
- `omission.bytesize > truncate_to` raises; message interpolates `omission.inspect` and both sizes.
- `nil` is `""`, so budget 0 with nil/empty omission is the equal-omission arm, not an error.
- Fitting-receiver short-circuit (row 9) still wins over a huge omission.

**Quirk to preserve (do not fix):** the equal-omission arm returns `omission.dup`, whose class is the omission’s class, **not** `self.class`. See rows 71–73.

## 8. Receiver mutation, identity, frozen

All of these must hold after every successful call:

1. `result.equal?(receiver) == false`
2. Receiver bytes, encoding, frozen flag, and class are unchanged
3. Result is **unfrozen**, even when the receiver or the omission is frozen
4. Mutating the result does not mutate the receiver or the omission

Concrete cases:

| # | setup | call | extra asserts |
|---|-------|------|---------------|
| 74 | `s = "Hello World"` | `r = s.truncate_bytes(8, omission: "...")`; `r << "MUTATED"` | `r == "Hello...MUTATED"`, `s == "Hello World"` |
| 75 | `s = "hello"` | `r = s.truncate_bytes(10)`; `r << "X"` | `r == "helloX"`, `s == "hello"` |
| 76 | `s = "Hello World".freeze` | `r = s.truncate_bytes(8, omission: "...")`; `r << "X"` | `r == "Hello...X"`, `s == "Hello World"`, `s.frozen?`, `!r.frozen?` |
| 77 | `s = "hello".freeze` | `r = s.truncate_bytes(5)`; `r << "X"` | `r == "helloX"`, `s == "hello"`, `s.frozen?`, `!r.frozen?` |
| 78 | `s = MyString.new("Hello World"); s.freeze` | `r = s.truncate_bytes(8, omission: "...")`; `r << "X"` | `r.class == MyString`, `!r.frozen?`, receiver still frozen `"Hello World"` |

| 80 | `s = MyString.new("Hello World")` | `r = s.truncate_bytes(8, omission: "...")`; `r.replace("Z")` | `r == "Z"`, `s == "Hello World"` |

**What this proves:** every arm allocates (`dup`, `omission.dup`, or `self.class.new`). Frozen receivers stay frozen and are never written. Results are always mutable. `replace` on a subclass result still does not alias the receiver.

## How to run it

One table-driven script (or a Minitest file) that:

1. Pins every receiver as a local variable (so identity/mutation checks are possible).
2. Records a pre-call snapshot: `value.dup`, `encoding`, `class`, `frozen?`, `object_id`.
3. Calls the method.
4. Asserts the columns above.
5. Mutates the result; re-asserts the snapshot.
6. For error rows, asserts `e.class` and `e.message` with `assert_equal`, not a regex.

Do **not** assert `bytesize == truncate_to` in general — rows 21, 23, 27, 28, 34, 36, 39, 45, 48, 52 show the result can be smaller.

Pass criterion: every row matches. A refactor that returns `self` on the fit path, freezes the result, uses `self.class` on the equal-omission path, splits `e\u0301`, or raises on a huge omission for a fitting receiver is a behavior change.
