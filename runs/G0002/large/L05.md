`Array#excluding` (aliased as `without`) returns `self - elements.flatten(1)`, so splatted values and a single wrapping array are treated the same, but flattening stops at one level. Nested arrays in the receiver are compared as whole elements, which is why `[[0, 1], [1, 0]].excluding([[1, 0]])` yields `[[0, 1]]` rather than descending into inner arrays. `Array#-` drops every equal occurrence from the copy, so excluded values disappear even if they were duplicated, while unmatched duplicates stay. The receiver is not mutated; a new array is returned.
