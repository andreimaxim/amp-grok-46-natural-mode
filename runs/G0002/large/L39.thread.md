def render_attachments(**options, &block)
  content = fragment.replace(ActionText::Attachment.tag_name) do |node|
    if node.key?("content")
      sanitized_content = sanitize_content_attachment(node.remove_attribute("content").to_s)
      node["content"] = sanitized_content if sanitized_content.present?
    end
    block.call(attachment_for_node(node, **options))
  end
  self.class.new(content, canonicalize: false)
end

def to_plain_text
  render_attachments(with_full_attributes: false, &:to_plain_text).fragment.to_plain_text
end

## Assistant

The observable contract on this revision is: `#to_plain_text` is a pure projection. It walks a canonicalized fragment, replaces each attachment with that attachable’s plain-text token, then runs `PlainTextConversion`. It must not rewrite the receiver’s HTML.

```diagram
ActionText::Content#to_plain_text
  │
  ├─ render_attachments(with_full_attributes: false)
  │     fragment.replace("action-text-attachment")  [dup, not in-place]
  │       sanitize node["content"] on the copy only
  │       attachment_for_node(node, with_full_attributes: false)
  │       yield attachment.to_plain_text  → string token
  │     new Content(..., canonicalize: false)
  │
  └─ .fragment.to_plain_text
        PlainTextConversion.node_to_plain_text
```

### Observable contract

**Construction.** `Content.new(html)` canonicalizes first: Trix figures → attachment tags, attachment inner HTML emptied, gallery wrappers reduced to `<div>…</div>`. Nested attachment tags inside another attachment are discarded at minify time, so they never reach conversion.

**`#to_plain_text`.** Always `render_attachments(with_full_attributes: false, &:to_plain_text).fragment.to_plain_text`. The block returns a **string**, so the working copy’s attachment nodes are replaced by text, then block/line rules run. Repeatable. Result is **not** html_safe.

**Attachment tokens** (`Attachment#to_plain_text`):

| Attachable | Token | Caption used? |
|---|---|---|
| `ActiveStorage::Blob` | `[caption \|\| filename]` | yes, else blob filename |
| `RemoteImage` | `[caption \|\| "Image"]` | yes, else `"Image"` |
| `MissingAttachable` | `☒` | **ignored** |
| `ContentAttachment` | inner HTML run through conversion | caption ignored |
| anything else (Page, Person) | `caption.to_s` | empty string if missing |

Blob filename on the **node** is ignored; representation reads the attachable. Observed: node `filename="from-node.gif"` still yields `[racecar.jpg]`.

**`#render_attachments`.** Dup-and-replace. Sanitizes `content` on the copy; drops it if sanitization leaves it blank. Returns a **new** `Content` with `canonicalize: false`. Default `with_full_attributes: true` expands blob nodes with `content-type`, `filename`, `filesize`, `previewable`. `false` leaves node attributes as stored. `#to_plain_text` must keep `false`.

**Markup conversion** (after attachment substitution):

- `p`, `h1`–`h6`: children + `"\n\n"`
- `div`: children + `"\n"`
- `br`: `"\n"`
- `ul`/`ol`: block spacing; nested lists get a leading `"\n"`
- `li`: `"• "` or `"1. "` etc.; nested indent `"  "` per extra list depth; orphan `li` still bullets
- `blockquote`: wrap first/last non-whitespace with `“` `”`; whitespace-only → `"“”"`
- `figcaption`: `[…]`
- `script` / `style`: dropped
- other elements: concatenate children (inline tags vanish, their text stays)
- trailing newlines stripped at the root

**Entities.** Tags are removed; entity **references** become real characters in the String (`&lt;script&gt;…` → `"<script>alert()</script>"`). That string is unsafe to put in HTML without sanitizing again.

**Non-mutation.** Receiver `to_html`, `as_json`, `inspect`, fragment `object_id`, and attachment `content` attributes stay identical before/after `#to_plain_text`. `#to_s` (layout HTML) is also unchanged. Isolation is `Fragment#update` duping `source`.
