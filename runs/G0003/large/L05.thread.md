## Assistant

`Array#excluding` (aliased as `without`) returns `self - elements.flatten(1)`, so both `excluding(3, 5)` and `excluding([3, 5])` drop `3` and `5`, but flattening is only one level. Nested arrays are therefore excluded as whole elements only when they survive that flatten: `[[0, 1], [1, 0]].excluding([[1, 0]])` yields `[[0, 1]]`, whereas `excluding([1, 0])` subtracts the integers `1` and `0`. Because the implementation uses `Array#-`, every matching occurrence is removed and leftover duplicates in the receiver are kept. The receiver is not mutated; a new array is returned.
