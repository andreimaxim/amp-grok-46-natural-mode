## Two layers to keep separate

**Security invariants (must not drift):** unsafe text must not enter a still-safe buffer unescaped; `html_safe` text must not be re-escaped; `safe_concat` is a raw trusted path and must refuse a dirty receiver; once `@html_unsafe` is set, later concat/`%` must **not** start escaping (dirty buffer is raw `String` concatenation); `+` is `dup.concat`, so a **safe left** operand still escapes a dirty right operand.

**String compatibility (may look like “just String”):** `concat`/`<<`/`safe_concat` mutate and return the receiver; `%` and `*` allocate; `dup` copies the flag; `nil` concat is a no-op; integer concat is a codepoint (`13` → `"\r"`); `is_a?(String)` stays true.

A refactor that preserves bytes but drops `SafeBuffer`, or preserves `SafeBuffer` but flips `html_safe?`, is a fail even if `==` matches.
