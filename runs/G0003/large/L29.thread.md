```text
    head :not_modified if request.fresh?(response)
  stale? then returns !request.fresh?(response)

request.fresh?(response)
  if_none_match / if_modified_since
  etag_matches?  → INM list includes response.etag or "*"
  not_modified?  → IMS >= response.last_modified
  strict_freshness true  → INM wins; IMS only if INM absent
  strict_freshness false → both present ⇒ AND

response
  ETag: W/"hex" (weak) or "hex" (strong)
  Last-Modified: HTTP-date (seconds)
  304: Head sets body ""; status 304; no content-type
  Cache-Control: default max-age=0, private, must-revalidate
                 if etag/LM set and header still empty
```

### Public HTTP contract to pin

Do not assert `combine_etags`, `etaggers`, or that `stale?` calls `fresh_when`. Pin wire behavior:

- Same validators → stable `ETag` / `Last-Modified` across requests.
- Matching `If-None-Match` or fresh `If-Modified-Since` → `304`, empty body, validators still present.
- Mismatch → `200`, body rendered, same validators.
- Weak vs strong is the `W/` prefix; matching is exact string equality.
- `If-None-Match: *` matches any present ETag, not a missing one.
- Default freshness is AND of both headers; `strict_freshness` makes INM win.
- `Last-Modified` is HTTP-date (seconds). Subseconds do not participate.
- Rails does **not** gate on method: GET, HEAD, QUERY, and POST currently `304` the same way. That is the contract to keep, not RFC 9110’s `412` on unsafe methods.
- `fresh_when` clears `no_store`; later `no_store` wins. `public: true` vs default private is visible on `Cache-Control`.
- Base includes template digest in ETags; `template: false` omits it; API has no template etagger.

### Fixture

One `ActionController::TestCase` controller (plus a second API controller only for “no template digest”). Frozen clock. Cheap instrumentation: `@work` incremented inside the `stale?` branch — not method spies.

```ruby
class FreshnessController < ActionController::Base
  self.view_paths = [ActionView::FixtureResolver.new(
    "freshness/show.erb" => "SHOW",
    "freshness/other.erb" => "OTHER"
  )]

  Record = Struct.new(:updated_at, :cache_key)

  def show
    @work = 0
    rec = Record.new(Time.utc(2024, 1, 15, 12, 0, 0, 123_456), "posts/1")
    if stale?(rec, **freshness_opts)
      @work += 1
      render plain: "body-#{@work}"
    end
  end

  def show_fresh_when
    rec = Record.new(Time.utc(2024, 1, 15, 12, 0, 0), "posts/1")
    fresh_when(rec, **freshness_opts)
    render plain: "body" unless performed?
  end

  def strong
    render plain: "body" if stale?(strong_etag: "payload", template: false)
  end

  def weak
    render plain: "body" if stale?(etag: "payload", template: false)
  end

  def lm_only
    render plain: "body" if stale?(last_modified: Time.utc(2024, 1, 15, 12, 0, 0, 123_456), template: false)
  end

  def with_template
    render plain: "stale" if stale?(template: "freshness/show")
  end

  attr_reader :work
  helper_method :work if false

  private
    def freshness_opts
      opts = {}
      opts[:public] = true if params[:public]
      opts[:template] = false if params[:no_template]
      opts[:strong_etag] = params[:strong] if params[:strong]
      opts[:cache_control] = { no_cache: true } if params[:no_cache]
      opts
    end
end
```

Capture ETag from an unconditioned GET; feed it back as `If-None-Match`. Do not rebuild hex digests in the matrix (existing `EtagHelper` tests already pin hashing).

Instrument work with `controller.instance_variable_get(:@work)` after the request, or expose it on a header only in this test controller (`response.set_header("X-Work", @work)` before render/`head`). Prefer the instance variable so production headers stay untouched.
