`Array.wrap` is a three-branch class method on `Array`. It never calls `to_a`. It returns `[]` for `nil`, otherwise the result of `to_ary` when that method is advertised, and otherwise a one-element array around the original object.

```text
Array.wrap(object)
  object.nil?                 → []
  object.respond_to?(:to_ary) → object.to_ary || [object]
  else                        → [object]
```

The implementation is [activesupport/lib/active_support/core_ext/array/wrap.rb](file:///home/user/workspace/repo/activesupport/lib/active_support/core_ext/array/wrap.rb):

```39:46:activesupport/lib/active_support/core_ext/array/wrap.rb
  def self.wrap(object)
    if object.nil?
      []
    elsif object.respond_to?(:to_ary)
      object.to_ary || [object]
    else
      [object]
    end
  end
```
