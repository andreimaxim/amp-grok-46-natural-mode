## Assistant

`Array#excluding` (aliased as `without`) returns a new array via `self - elements.flatten(1)`, so splatted args and a single nested array of items are equivalent (`excluding(2, 3)` and `excluding([2, 3])` both drop `2` and `3`). Flattening is only one level, so a nested array is removed only when it is passed as an element after that flatten (`excluding([[1, 0]])` drops `[1, 0]`; `excluding([1, 0])` looks for top-level `1` and `0` and leaves nested pairs alone). `Array#-` removes every occurrence of each excluded value, while leftover duplicates of kept values stay. The receiver is not mutated.
