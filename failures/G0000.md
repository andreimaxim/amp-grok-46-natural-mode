# G0000 — failed small (2/5)

Baseline official prompt. Two matches (explanatory walkthroughs), three misses (two review comments, one verification strategy). Every miss reached the same top-level conclusion as the references; the judge rejected them for concrete supporting claims that were false.

## Patterns

**Unexecuted concrete claims (all three misses, several times each).** The candidate read the implementation, then stated specific outcomes for inputs it never ran or looked up, with the same confidence as the facts it had checked. Forms it took:

- Filling in a table of expected outputs by extrapolating from the few cases the probe script actually ran; the unprobed cells were wrong, so the proposed oracle would misreport a correct refactor.
- Carrying a probe result observed on one input over to a different input in the write-up, producing an impossible example.
- Predicting what a proposed change "would" do to a nested value ("becomes X, loses Y") without executing that path; the real outcome depends on a condition the candidate never mentioned and the references did.
- Dismissing the contributor's rationale with a categorical negative ("nothing useful ... that is not already on the exception") without reading the class whose contents the claim was about.
- Naming a later call as one that would observe stale state without reading that call; it resets the state first.

The references either executed the exact case and quoted the result, or stated the condition the outcome depends on. The candidate's investigation volume was comparable (it ran a broad probe in one case); the gap is between what it verified and what it asserted.

**Missed an explicitly requested sub-question (one-off).** One review was asked for return behavior and never stated the return contract of the outer method, only that the recursive branch was unchanged.

**Over-investigation without harm (one-off, matched case).** The judge noted one matched answer was "somewhat more investigative than necessary". Not a failure cause.
