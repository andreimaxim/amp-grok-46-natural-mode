Behavior-preservation plan for a refactor of `ActionText::Content#to_plain_text` and `#render_attachments` at [`d59d106f94`](https://github.com/andreimaxim/rails-for-grok-large/commit/d59d106f94dcb7e8e748545c0ccf8a276d20f590). These files match that revision. Expected strings were executed here, not inferred from docs. The RDoc on `to_plain_text` says “HTML entities encoded”; observed behavior **decodes** them.

This is a characterization/test plan only. Do not change production code yet.

### Pipeline that must stay equivalent

```text
Content#to_plain_text
  -> render_attachments(with_full_attributes: false, &:to_plain_text)
     -> Fragment#replace("action-text-attachment") on a duplicated source
     -> optionally sanitize the duplicated node's `content` attribute
     -> yield Attachment.from_node(node) without with_full_attributes
     -> replace node with block result (skip string-replace if same node object)
     -> Content.new(result, canonicalize: false)
  -> Fragment#to_plain_text / PlainTextConversion bottom-up reducer
```

Non-negotiable:

- `to_plain_text` must keep `with_full_attributes: false`.
- `render_attachments` must duplicate the fragment and return a **new** `Content`.
- Result construction must use `canonicalize: false`.
- Do not route this through `to_s`, layouts, controller/mailer rendering, or gallery HTML partials.
- Same-node replacement must keep the existing `node != replacement_node` skip.
- Canonicalization (minify inner HTML, gallery class stripping, raw-markdown unwrap) belongs to `Content.new`, not to `to_plain_text`.

Return type: UTF-8 `String`, `html_safe? == false`. Not safe to re-render as HTML.

### Assertion categories

Use exact `assert_equal` on strings (whitespace, `•`, `“”`, `☒`, brackets). Do not assert via `to_s` or rendered layouts.

#### 1. Ordinary block / line-break markup

Oracle: `ActionText::Content.new(html).to_plain_text`. Already evidenced in [plain_text_conversion_test.rb](file:///home/user/workspace/repo/actiontext/test/unit/plain_text_conversion_test.rb#L6-L154):

| Input | Expected |
|---|---|
| `<p>Hello world!</p><p>How are you?</p>` | `"Hello world!\n\nHow are you?"` |
| `<h1>…</h1><div>…</div>` and h2–h6 | paragraph spacing `"\n\n"` |
| sibling `<div>`s | one newline |
| `<br>` | `"\n"` |
| `<ul><li>…` | `"• one\n• two\n• three"` |
| nested ul/ol | two-space indent per extra depth; mixed list form already pinned at L92–96 |
| `<blockquote>Hello world!</blockquote>` | `"“Hello world!”"` |
| whitespace-only blockquote | `"“”"` |
| `<figcaption>…</figcaption>` | `[caption]` |
| inline/unknown tags | tags dropped, children kept |
| 10,000 nested `<div>`s | still converts (L127–139) |

Root trailing newlines are chomped. Comments drop (`"Hello<!-- hidden -->world"` → `"Helloworld"`) — **needs a characterization test**.

#### 2. Entities and script-like text

Executed on this revision. Existing tests cover real `<script>`/`<style>` **nodes** (L156–178), not encoded text.

| Input | Expected `to_plain_text` |
|---|---|
| `&amp; &nbsp; &lt;script&gt;alert()&lt;/script&gt;` | `"& \u00A0 <script>alert()</script>"` (nbsp is U+00A0) |
| `&lt;script&gt;alert()&lt;/script&gt;` | `"<script>alert()</script>"` (matches content.rb L129–130) |
| `<div onclick='action()'>safe<script>unsafe</script></div>` | `"safe"`; `to_html` still contains the script node |

Also assert `html_safe? == false` and that `to_html` stays encoded. Plain text does not sanitize attributes.

#### 3. Attachment captions and filenames

`Attachment#to_plain_text` runs **before** DOM reduction. Hook: `attachable_plain_text_representation(caption)` if present, else raw `caption.to_s` with **no automatic brackets**.

| Kind | Expected |
|---|---|
| Blob + caption through `Content` | `"[Captioned]"` |
| Blob, no caption | `"[racecar.jpg]"` |
| Blob + caption + filename attr | `"[Cap]"` (caption wins) |
| Remote image + caption | `"[Cat]"` (already L120–125) |
| Remote image, no caption | `"[Image]"` |
| Remote + filename, no caption | `"[Image]"` — node filename does **not** substitute |
| Page / Person (no hook) + caption | `"The caption"` (raw, no brackets) |
| Page, no caption | `""` |
| ContentAttachment `<p>abc</p>` | `"abc"` (inner HTML injected, then reduced) |
| ContentAttachment two `<p>`s | `"abc\n\ndef"` |

Existing [attachment_test.rb L55–58](file:///home/user/workspace/repo/actiontext/test/unit/attachment_test.rb#L55-L58) tests `Attachment.from_attachable` only, not the Content path. Surrounding markup executed: `<p>Hello</p><attachment caption=Cap><p>world</p>` → `"Hello\n\n[Cap]world"`.

#### 4. Missing attachables

Always `☒`; caption is ignored.

- `sgid="missing"` with caption → `"☒"`
- destroyed blob, with or without caption → `"☒"` ([content_test.rb L91–97](file:///home/user/workspace/repo/actiontext/test/unit/content_test.rb#L91-L97) covers destroyed **without** caption)
- `content-type="image/*" url="image.png"` (non-URI) → MissingAttachable → `"☒"` (L58–66 classifies, does **not** assert plain text)

#### 5. Duplicate attachables

Two nodes, same blob sgid, captions A and B → `"[A][B]"`. No plain-text deduplication. **Needs characterization.** (`model_test.rb` L55–61 only covers embed extraction / save.)

#### 6. Attachment galleries

Canonical HTML already evidenced ([content_test.rb L127–143](file:///home/user/workspace/repo/actiontext/test/unit/content_test.rb#L127-L143)): gallery wrapper classes stripped to `<div>…</div>`, whitespace inside preserved in HTML.

Plain text **needs characterization**. Executed:

| Input | `to_plain_text` |
|---|---|
| two gallery blobs, no extra whitespace | `"[One][Two]"` |
| same with `"\n  "` between nodes | `"\n  [One]\n  [Two]"` |
| same inside `<blockquote>` | `"\n  “[One]\n  [Two]”"` |
| gallery with bogus sgids `1`/`2` | `"☒☒"` / `"\n  ☒\n  ☒"` |

Gallery whitespace text nodes are significant. Do not normalize them away.

#### 7. Nested attachment nodes

Executed; **needs characterization.**

| Construction | `to_html` | `to_plain_text` |
|---|---|---|
| default canonicalize | inner child minified away | `"☒"` (missing sgid) |
| `canonicalize: false` | inner child retained in HTML | still `"☒"` — replacing the **outer** node discards descendants |
| inner `<div>INNER</div>`, `canonicalize: false` | inner HTML kept on original | render result HTML is just `☒` |

#### 8. `with_full_attributes: false`

Text equality is **not** a sufficient oracle. Executed for a blob node with only `sgid` + `caption="Cap"`:

- both flag values yield `"[Cap]"`
- `false`: yielded node HTML stays at original attributes (`sgid`, `caption`)
- default `true`: expands to `content-type`, `filename`, `filesize`, `previewable`

Assert **yielded node HTML / attribute keys**. Existing analogue: [markdown_conversion_test.rb L1124–1136](file:///home/user/workspace/repo/actiontext/test/unit/markdown_conversion_test.rb#L1124-L1136).

#### 9. Non-mutation of `#to_html` / canonical content

Executed: html equal, source oid equal, not html_safe, repeatable.

```ruby
html_before = content.to_html.dup
source_oid  = content.fragment.source.object_id
plain = content.to_plain_text

assert_equal html_before, content.to_html
assert_equal source_oid, content.fragment.source.object_id
assert_not plain.html_safe?
assert_equal plain, content.to_plain_text
assert_not_equal content.object_id, content.render_attachments { |a| a }.object_id
```

`render_attachments` sanitizes `content="…"` **only on the duplicate**:

| Original | Rendered (`{ |a| a }`) |
|---|---|
| `content="<img … onerror=alert>"` | `onerror` stripped; original still has it |
| `content=""` | attribute removed on result |
| `content="<script></script>"` | attribute removed on result |

Existing sanitization tests go through `to_trix_html`, not this path. Renderer may be nil; blob `to_plain_text` still returns `"[racecar.jpg]"`.

### Unit vs integration

**Unit (keep running):**

- `plain_text_conversion_test.rb` — already composed `Content#to_plain_text` for markup
- `attachment_test.rb` L55–58 — `Attachment#to_plain_text` in isolation
- attachable representation methods (blob, Missing `☒`, RemoteImage, ContentAttachment)

**Characterization to add before refactor** (all via `Content#to_plain_text` or `Content#render_attachments`):

1. Entities, encoded script-like text, comments, `html_safe? == false`, UTF-8
2. Blob-through-Content; remote no-caption / filename-ignored; missing caption ignored; invalid remote URL → `☒`
3. ContentAttachment inner reduction; Page/Person raw caption / empty; duplicates `[A][B]`
4. Gallery concatenation, retained whitespace, blockquote wrapping
5. Nested attachments (canonicalize vs `canonicalize: false`)
6. `with_full_attributes: false` vs default true via yielded node HTML
7. `render_attachments` new-object identity, result-only `content` sanitization
8. Non-mutation of `to_html` and fragment `source.object_id`

**Do not use as primary oracle:** `to_s` / layouts, controller/mailer/job render tests, `to_markdown` except as the `canonicalize: false` analogue.
