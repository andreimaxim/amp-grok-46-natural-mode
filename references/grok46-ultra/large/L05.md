`Array#excluding` (aliased as `without`) returns a new array via `self - elements.flatten(1)`, so splatted args and a single wrapper array are equivalent (`excluding(1, 2)` and `excluding([1, 2])` both drop `1` and `2`). Flattening is only one level, so nested arrays stay values to exclude: `[[0, 1], [1, 0]].excluding([[1, 0]])` is `[[0, 1]]`. `Array#-` removes every `eql?` match, so duplicates of an excluded element are all gone. The receiver is not mutated.
