`#none` is a Null Object for relations. It stays a `Relation` so callers can keep chaining. Emptiness is an instance flag plus a dummy predicate, not `[]`.

```ruby
def none
  spawn.none!
end

    where!("1=0")
    @none = true
  end
  self
```

### Chainability

`#none` is `spawn.none!`, so the original relation is unchanged. Later `where` / `order` / `limit` / `joins` also `spawn`, so they clone the flag. The result is still a null relation.

`Merger` copies it in one direction:

`Post.where(...).merge(Post.none)` becomes none. `Post.none.merge(Post.where(...))` is already none from the clone, so it stays none even though `other` is not a null relation.

```ruby
  else
```
