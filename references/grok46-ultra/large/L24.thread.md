### 5. Two unescape layers for dynamic segments

**Layer 1 — Journey captures** ([router.rb:73-81](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/journey/router.rb#L73-L81)): if the capture contains `%`, `CGI.unescapeURIComponent`, then `force_encoding(UTF_8)`. `+` is *not* a space. Tests:

- [test_paths_escaped](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L587-L601): `hello+world` stays `hello+world`; `%20` becomes space; `%3F` becomes `?`
- [test_default_route_should_uri_escape_pluses](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L1874-L1883): `hello+world` and `hello%2Bworld` both yield `"hello+world"`; `%20` yields `"hello world"`
- [test_escapes_newline_character_for_dynamic_path / wildcard](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L651-L665): `%0A` → `"\n"`
- [UriReservedCharactersRoutingTest](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L37-L46): reserved path bytes round-trip through percent-decoding

**Layer 2 — RouteSet** ([route_set.rb:928-933](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/routing/route_set.rb#L928-L933)): after extras merge, every String (captures, string defaults, extras) is BINARY then `URI::RFC2396_PARSER.unescape`. Non-strings (`:as_symbol`, `ws: true`, integer defaults) are left alone ([test_recognize_path:2097, 2109](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L2097-L2109)).

Consequence of the double pass: a still-percent-encoded value after Journey (`%2520` → `%20`) is decoded again by RouteSet (`%20` → space). Values without `%` are unchanged by both layers.

Then `req.path_parameters = params` runs encoding checks ([parameters.rb:67-76](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/http/parameters.rb#L67-L76)): invalid encoding → `ActionController::BadRequest`.

### 6. App-level constraints, dispatcher vs engine

`route.app` is usually `Dispatcher`, `Mapper::Constraints`, or a mounted engine ([mapper.rb Mapping#app](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/routing/mapper.rb#L290-L298)).

`app.matches?(req)` here is *not* `Route#matches?`. It is the Constraints wrapper’s callables/objects ([mapper.rb:52-57](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/routing/mapper.rb#L52-L57)), re-checked now that `req.path_parameters` is populated — so lambdas can read `request.params[:name]` ([test_route_with_subdomain_and_constraints_must_receive_params](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L1691-L1700)).

Only then:

- **dispatcher?** → try `req.controller_class`, return `req.path_parameters`
- **engine?** → recurse `recognize_path_with_request(..., raise_on_missing: false)`. A miss returns `nil` and the parent keeps iterating. A hit returns the engine’s path params. Tests: [engine recognition](file:///home/user/workspace/repo/actionpack/test/dispatch/routing_assertions_test.rb#L137-L185).
- Redirect / plain Rack / failed `app.matches?` → do not return; try the next Journey yield.

### 7. Missing controller vs unmatched route

`Request#controller_class` ([request.rb:85-106](file:///home/user/workspace/repo/actionpack/lib/action_dispatch/http/request.rb#L85-L106)): `#{controller.underscore.camelize}Controller`.constantize. Missing constant becomes `ActionDispatch::MissingController < NameError`.

`recognize_path_with_request` rescues `NameError` and raises:

```text
ActionController::RoutingError
  "A route matches #{path.inspect}, but references missing controller: #{params[:controller].camelize}Controller"
```

If Journey yields nothing that is an accepted dispatcher/engine, the outer call with `raise_on_missing: true` raises:

```text
ActionController::RoutingError
  "No route matches #{path.inspect}"
```

Engine recursion uses `raise_on_missing: false`, so an engine miss is `nil`, not an exception.

Observable matrix:

| Case | Result |
|---|---|
| Path matches a dispatcher and controller exists | Hash of symbol keys: `controller`, `action`, captures, defaults, extras |
| Path matches, controller cannot constantize | `RoutingError` “A route matches … missing controller: FooController” |
| No route / verb mismatch / request constraint fail / optional segment missing | `RoutingError` “No route matches …” |
| Engine prefix matches but inner routes don’t, and a later parent route does | Parent route’s params |
| Engine prefix matches, inner routes don’t, nothing else matches | “No route matches” (parent, not the engine) |
| `nil` path with a root route | `{controller:, action: "index"}` (normalized to `/`) |
| Invalid URI | `RoutingError` wrapping `URI::InvalidURIError` message |
| Invalid encoding in a path param | `ActionController::BadRequest` from `path_parameters=` |

Tests that pin this:

- Unmatched path: [test_recognize_path `/none`](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L2137); [test_default_route_recognition `/` and overlong path](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L1860-L1861); regexp controller that does not capture `/admin/products` ([test_route_with_regexp_and_captures_for_controller](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L414)).
- Verb mismatch as unmatched: PUT/DELETE on `get_or_post` ([2103](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L2103)); missing optional ([2107](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L2107)).
- Dynamic `:controller` whose constant does not exist: [test_non_controllers_cannot_be_matched](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L614-L621) — `recognize_path("/not_a/show/10")` raises `RoutingError` (this is the missing-controller branch: the `/:controller/:action/:id` pattern matches, then constantize fails).
- Live dispatch is a different exception: [test_route_error_with_missing_controller](file:///home/user/workspace/repo/actionpack/test/controller/routing_test.rb#L1278-L1284) uses `request_path_params` → `RouteSet#call` → `Dispatcher#serve` → `MissingController`, not `recognize_path`. For `to: "does_not_exists#index"`, `dispatcher(true)` so the NameError is not swallowed. Do not conflate that with `recognize_path`.

`raise_on_name_error` on `Dispatcher` only affects live `serve`, not `recognize_path`. `recognize_path` always constantizes dispatcher targets.

### Return value

Success returns `req.path_parameters`: a Hash with **symbol keys**, stored under `action_dispatch.request.path_parameters`. It is not `request.params` (no QUERY_STRING / body). `action` is whatever Journey merged from defaults/captures; `controller_class` may set `params[:action] ||= "index"` on the same hash as a side effect of the constantize check.
