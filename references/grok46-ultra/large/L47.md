A refactor of Railties autoload-path assembly is behavior-preserving iff these **externally observable** facts stay the same. Do not assert private concatenation order of `config.all_*` or `Engine#_all_*`. Assert loader ownership, constant identity/removal, `$LOAD_PATH` membership, freeze/error, and callback **counts**.

### Current assembly (source of invariants)

Path math (custom arrays first, then `Rails::Paths`):

- [`Rails::Engine::Configuration#all_autoload_paths`](file:///home/user/workspace/repo/railties/lib/rails/engine/configuration.rb) = `autoload_paths + paths.autoload_paths`
- `#all_autoload_once_paths` = `autoload_once_paths + paths.autoload_once`
- `#all_eager_load_paths` = `eager_load_paths + paths.eager_load`

Engine registration in [`railties/lib/rails/engine.rb`](file:///home/user/workspace/repo/railties/lib/rails/engine.rb):

- `_all_autoload_once_paths` → `all_autoload_once_paths.uniq`
- `_all_autoload_paths` → `(all_autoload_paths + all_eager_load_paths - all_autoload_once_paths).uniq` (memoized)
- `_all_load_paths` → `paths.load_paths` plus the two lists above iff `app.config.add_autoload_paths_to_load_path`

Initializers, in this order:

1. **Per engine, before `:bootstrap_hook`**: `set_load_path`, `set_autoload_paths`, `set_eager_load_paths`
   - `$LOAD_PATH.unshift` existent dirs, then `$LOAD_PATH.uniq!`
   - `Dependencies.autoload_paths.unshift(*_all_autoload_paths)`
   - `Dependencies.autoload_once_paths.unshift(*_all_autoload_once_paths)`
   - freeze **custom** `config.autoload_paths` / `autoload_once_paths` / `eager_load_paths`
   - merge eager dirs into `Dependencies._eager_load_paths` (`Set`)
2. **Once, still before `:bootstrap_hook`**: `setup_once_autoloader` in [`bootstrap.rb`](file:///home/user/workspace/repo/railties/lib/rails/application/bootstrap.rb)
   - freeze `Dependencies.autoload_once_paths`
   - `once.push_dir` for existent dirs not already configured; `do_not_eager_load` unless `Dependencies.eager_load?(path)`; `once.setup`
3. **Finisher**: `setup_main_autoloader` in [`finisher.rb`](file:///home/user/workspace/repo/railties/lib/rails/application/finisher.rb)
   - freeze `Dependencies.autoload_paths`
   - same `push_dir` / `do_not_eager_load` rules on `main`
   - if reloading: `main.enable_reloading`, `Dependencies.autoloader = main`
4. Reloader: `watchable_args` watches **`main.dirs` only**; `Dependencies.clear` → `main.reload`; if eager+reload, `after_class_unload { main.eager_load }`

[`Rails::Paths::Root#filter_by`](file:///home/user/workspace/repo/railties/lib/rails/paths.rb) already drops non-directories and child dirs whose parent is the flagged path. Zeitwerk also skips non-directories.

### Invariants (must survive the refactor)

| ID | Invariant | Observable, not private order |
|----|-----------|-------------------------------|
| I1 | Every existent custom + `paths` autoload dir that is **not** once is a **main** root. | `dir ∈ Rails.autoloaders.main.dirs` |
| I2 | Every existent once dir is a **once** root and **not** a main root. | `dir ∈ once.dirs` ∧ `dir ∉ main.dirs` |
| I3 | Eager-only dirs (in eager, not once) are also main roots (because `_all_autoload_paths` unions eager). | constant in that dir autoloads from main |
| I4 | A dir in **both** eager and once is owned by **once**, and **is** eager-loaded (once does not `do_not_eager_load`). | production boot defines the constant; `main.dirs` excludes it |
| I5 | Duplicate entries in any input collection yield **one** root and one `$LOAD_PATH` entry. | `dirs.count(path) == 1`; `$LOAD_PATH.count(path) == 1` |
| I6 | Overlapping parent/child `app/` trees stay the current `Paths` filter (parent `app` eager-load does not double-register `app/models` as a separate root when it is a child). | set of `main.dirs` for a default app is unchanged as a **set** |
| I7 | `config.add_autoload_paths_to_load_path = false` (7.1+ default): autoload dirs are **not** in `$LOAD_PATH`, except **`lib`** (always unshifted by `Application.add_lib_to_load_path!`) and `paths.load_paths` (`lib`, `vendor`). | `$LOAD_PATH` membership |
| I8 | `add_autoload_paths_to_load_path = true`: every existent app/engine autoload and once dir is in `$LOAD_PATH`; mailer previews may still be in `Dependencies.autoload_paths` without being a `$LOAD_PATH` concern (existing test already rejects `mailers/previews`). | set inclusion |
| I9 | After the relevant initializer, mutating the frozen arrays raises `FrozenError`. Once is frozen by `:bootstrap_hook`; main `Dependencies.autoload_paths` is frozen at `setup_main_autoloader`. | `FrozenError` + `.frozen?` |
| I10 | Once constants are loadable **during initializers**; main is not set up until finisher. | `X` from a once dir is defined in an initializer `after: :bootstrap_hook` |
| I11 | Development reload: main constants are **new objects** after edit; once constants keep **object_id**. Removed main files → `NameError` after `reloader.reload!`. | identity / `NameError` |
| I12 | Production / `config.eager_load = true`: eager dirs load at boot; once-without-eager do **not** load until referenced. Engines’ `app/` code eager-loads. | boot-time side effects / `const_defined?` |
| I13 | Reloader watches **main** dirs only. Editing a once file does not reload that constant. `to_prepare` / `to_complete` / `after_class_unload` invocation **counts** stay the same. | callback counters, not callback list order |
| I14 | Engine and application paths both become roots. Engine `app/models/foo.rb` autoloads; application `app/models/bar.rb` autoloads; neither loader drops the other. | constant resolution + dir membership |
| I15 | User `push_dir(..., namespace:)` before setup is not overwritten (`already_configured_dirs`). | namespaced constant, not `Object::X` |
| I16 | Non-existent dirs are omitted from loaders (Zeitwerk forbids them) and do not raise at boot. | `dir ∉ *.dirs`; boot succeeds |
| I17 | `main.reloading_enabled?` iff `config.reloading_enabled?`; `once.reloading_enabled?` is always false. | predicates |
| I18 | `Dependencies.clear` / `reloader.reload!` reloads **main only**. | spy on `reload` or constant identity |

**Do not lock:** exact order of `unshift` across engines; exact `all_*` array equality; memoization of `@_all_autoload_paths`; `Set` vs `Array` internals of `_eager_load_paths`. Zeitwerk first-root-wins is observable **only** via which constant is defined when two roots define the same cpath — assert that winner, not `dirs.index`.

### New black-box probes (isolation tests; assert observables)

Add beside `zeitwerk_integration_test.rb` / `loading_test.rb`. Each probe boots a generated app (`build_app` / `engine(...)`). Prefer `assert_includes` / `assert_not_includes` / `assert_same` / `assert_not_equal object_id` / `assert_raises`.

#### 1. Duplicates and overlapping paths

```ruby
## same dir appended twice to autoload_paths
config.autoload_paths << "#{root}/extras"
config.autoload_paths << "#{root}/extras"
## extras/x.rb: module X; end
```

Assert:

- `Rails.autoloaders.main.dirs.count { _1 == extras } == 1`
- `X` autoloads once (`object_id` stable within a boot)
- `$LOAD_PATH.count(extras)` is 0 (default) or 1 (flag true)

Overlap parent/child: `config.autoload_paths << app/models` while `app` is already eager. Assert no Zeitwerk `Loader#push_dir` error at boot; `User` still loads; do **not** assert whether `app/models` is listed twice in `all_autoload_paths`.

#### 2. Path in both eager-load and autoload-once

```ruby
config.autoload_once_paths << "#{root}/serializers"
config.eager_load_paths    << "#{root}/serializers"
## serializers/money.rb defines Money
```

Production boot:

- `Object.const_defined?(:Money)` **before** any explicit reference
- `serializers ∈ once.dirs` and `serializers ∉ main.dirs`
- After `reloader.reload!` in a development app with `eager_load = true`: `assert_same money_id, Money.object_id` (once is not reloaded)

Contrast with eager+autoload (not once): `Money.object_id` **changes** after reload (existing re-eager test pattern).

#### 3. `config.add_autoload_paths_to_load_path = false`

Preconditions: new-app default is already false (7.1 `load_defaults`). Probe both false and explicit true.

False:

- `assert_not_includes $LOAD_PATH, "#{app}/app/models"`
- `assert_includes $LOAD_PATH, "#{app}/lib"`
- `require "user"` does **not** load `app/models/user.rb` (`LoadError`); `User` still autoloads via Zeitwerk
- engine `app/models` also absent from `$LOAD_PATH`; engine `lib` present

True:

- `assert_empty (existent_app_and_engine_autoload_dirs - $LOAD_PATH)` excluding mailer previews
- still `$LOAD_PATH.uniq` (duplicate engine+app lib does not appear twice)

#### 4. Development reload: edit and removal

Main dir `app/models/user.rb`:

1. Boot, `u1 = User.object_id`, `User::VERSION == 1`
2. Rewrite file to `VERSION = 2`; `Rails.application.reloader.reload!`
3. `assert_not_equal u1, User.object_id`; `User::VERSION == 2`
4. `File.delete` the file; `reload!`; `assert_raises(NameError) { User }`
5. Reloader user callbacks:

```ruby
counts = { prepare: 0, complete: 0, after_unload: 0 }
Rails.application.reloader.to_prepare { counts[:prepare] += 1 }
Rails.application.reloader.to_complete { counts[:complete] += 1 }
Rails.application.reloader.after_class_unload { counts[:after_unload] += 1 }
```

One `reload!` increments each by 1 (plus the prepare that already ran at boot — capture baseline before registering, or register before boot via `config.to_prepare`). Assert **deltas**, not callback chain length.

Once dir `extras/frozen_const.rb`:

- Edit + `reload!` → `assert_same id, FrozenConst.object_id` and old body still holds
- Delete file + `reload!` → constant **still defined** (once)

#### 5. Eager-loaded production

`boot("production")` (or `config.eager_load = true`):

- Side-effect flags in `app/models` and engine `app/models` are true at boot
- Side-effect in once-without-eager is false until constant reference
- `assert_not Rails.autoloaders.main.reloading_enabled?`
- `Rails.application.reloader.reload!` is a no-op for constants (`assert_same` main constant — or `reloader.check` is false). Do not require `reload!` to raise.

#### 6. Engine vs application paths

Engine gem with `app/models/engine_record.rb` and `extras/engine_once.rb` (`config.autoload_once_paths`); app with `app/models/app_record.rb`.

Assert:

- `EngineRecord` and `AppRecord` both defined
- `engine_root/app/models ∈ main.dirs` and `app/models ∈ main.dirs`
- engine extras `∈ once.dirs`, not `main.dirs`
- Isolated engine: same membership; constant still autoloads (existing engine tests already cover routing isolation — do not mix that in)

#### 7. Path arrays freeze after initialization

Use initializers to snapshot, then mutate after `app`:

| Collection | Frozen starting | Probe |
|------------|-----------------|-------|
| `config.autoload_paths` | `set_autoload_paths` (before bootstrap) | initializer `after: :bootstrap_hook` sees `.frozen?`; after boot `assert_raises(FrozenError) { config.autoload_paths << "x" }` |
| `config.autoload_once_paths` | same | already covered; keep |
| `config.eager_load_paths` | `set_eager_load_paths` | **missing today** — add `FrozenError` probe |
| `Dependencies.autoload_once_paths` | `setup_once_autoloader` | already covered |
| `Dependencies.autoload_paths` | `setup_main_autoloader` (finisher) | **not frozen at bootstrap_hook**; `FrozenError` **after** full boot |

Also: reading `config.autoload_paths` during configure then `config.paths.add(...)` still registers (existing #49629 test). That must keep working — it is the reason `all_*` must stay live concatenations until the engine initializers run.

### How to avoid order-only coupling

- Replace `assert_equal existing_autoload_paths, main.dirs` as a **preservation gate** with:
  - `assert_equal existing_autoload_paths.to_set, main.dirs.to_set`
  - plus one shadowing probe if two roots define `Foo`: assert which `Foo` wins **if** current Zeitwerk order is considered user-visible. If the refactor may reorder engine `unshift`, document that the winner may change and **do not** fail the suite on winner unless product says first-registered engine wins.
- For once extras `e1,e2,e3`, assert each `∈ once.dirs` and `∉ main.dirs` and that `E1,E2,E3` autoload; drop `slice(e1_index, length)`.
- Prefer `assert_includes` / set difference empty over `assert_equal` on full `$LOAD_PATH` or `Dependencies.autoload_paths`.
- Callback tests: increment counters; do not inspect `__callbacks` order.
- Do not assert `@_all_autoload_paths` identity, `uniq` vs `Set` implementation, or `reverse_each` on `$LOAD_PATH` beyond “membership + uniqueness”.
