Flattening is only one level, so nested arrays stay values to exclude: `[[0, 1], [1, 0]].excluding([[1, 0]])` is `[[0, 1]]`. `Array#-` removes every `eql?` match, so duplicates of an excluded element are all gone. The receiver is not mutated.
