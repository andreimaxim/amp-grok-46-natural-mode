Treat the current [`truncate_bytes`](activesupport/lib/active_support/core_ext/string/filters.rb) as the oracle. Capture one observation table before the refactor and replay it after. Pass/fail is exact equality of each tuple: returned bytes, `bytesize`, `encoding`, `class`, identity vs receiver/omission, receiver content after the call, and any exception. Existing tests miss ASCII, subclass/identity, and non-mutation, so a green suite is not proof.

Fixed fixtures: `"Hello World!"` (12), `"👍👍👍👍"` (16 = 4×4), `"a ❤️ b"` (10 = 1+1+6+1+1), `"👩‍❤️‍👩"` (20, one cluster), default omission `"…"` (3), `"🖖"` (4).

**Within-budget.** `"Hello World!".truncate_bytes(12)` and `"👍👍👍👍".truncate_bytes(16)` with any omission return a **copy** of the full string. Proves `bytesize <= truncate_to` uses `dup` and ignores omission.

**ASCII.** `"Hello World!".truncate_bytes(11)` → `"Hello Wo…"`; `(5, omission: nil)` → `"Hello"`. Proves the cut is in bytes, 1-byte graphemes fill greedily, and omission is inside the same budget.

**Multibyte.** Budget 15 → `"👍👍👍…"`; budget **14** → `"👍👍…"` (11 bytes), never a 14-byte invalid prefix. Proves codepoints are not split. `byteslice` rewrites fail here.

**Graphemes.** `"a ❤️ b".truncate_bytes(7, omission: nil)` → `"a "` (not `"a ❤"`); `"👩‍❤️‍👩".truncate_bytes(13, omission: nil)` → `""`. Proves the unit is a cluster: U+2764+U+FE0F and the 20-byte ZWJ sequence are refused unless the whole cluster fits.

**Exact boundaries.** Receiver==16 copies, 15 truncates (`<=`, not `<`). Prefix+omission==15 is exact. Cluster straddling `cut_at` (14) drops the cluster. Omission==budget returns only the omission.

**Custom / nil.** On budget 15: default `"👍👍👍…"`, `nil`/`""` → `"👍👍👍"`, `" "` → `"👍👍👍 "`, `"🖖"` → `"👍👍🖖"`. Proves nil is empty (not `"…"`) and omission consumes budget before the prefix is filled.

**Omission ≥ budget.** `"🖖"` at 4 returns `"🖖"` (a **dup**, not the same object). `"🖖"` at 3 raises `ArgumentError` with `Omission "🖖" is 4, larger than the truncation length of 3 bytes`. Equality must not raise; `>` must.

**Encoding / subclass.** Truncating UTF-8, US-ASCII, and BINARY keep the receiver encoding — including the empty result `"👩‍❤️‍👩".truncate_bytes(13, omission: nil)`, which is `force_encoding` vs bare `String.new` → ASCII-8BIT. A `TruncString < String` stays `TruncString` on the fit (`dup`) and truncate (`self.class.new`) branches, but the equal-omission branch returns a plain `String` (`omission.dup`).

**Mutation.** Frozen and unfrozen receivers keep content, encoding, and `object_id`. Result is never `equal?` to the receiver or the omission. Proves every branch allocates; none of `replace` / `slice!` / `self <<` / returning `self`.

Gate: `cd activesupport && bin/test test/core_ext/string_ext_test.rb -i /truncate_bytes/`. Behavior is unchanged only if every tuple matches the pre-refactor oracle.
