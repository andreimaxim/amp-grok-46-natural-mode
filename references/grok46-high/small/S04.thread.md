1. Block path: `capture` escapes raw strings and marks buffer output html_safe.
2. Direct append: `SafeBuffer#<<` HTML-escapes anything that is not already `html_safe?`.
3. `set` (`flush: true`) wraps `value.to_s` in a new `SafeBuffer` (marks safe; block content was already escaped by `capture`).
4. On read, the stored `SafeBuffer` is returned. When the layout buffer does `<<`, `html_safe?` is true, so it is concatenated without a second escape.

That is why `<%= content_for :title %>` / `<%= yield :title %>` can splice named content into the layout without double-escaping, and why a raw string passed as direct content is escaped on append unless it was already marked safe (`raw`, `content_tag`, etc.).
