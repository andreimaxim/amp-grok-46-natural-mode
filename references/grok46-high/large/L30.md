## Verification strategy for an internal `ActionController::Live#send_stream` refactor

Behavior-preservation only. No implementation changes. Checks attach to public seams (`send_stream` options, headers/body/stream, notifications, exceptions, thread/IES, logger), not private layout (`new_controller_thread`, `clean_up_thread_locals`, `each_chunk`, `build_queue`).

Primary sources: [`live.rb`](actionpack/lib/action_controller/metal/live.rb), [`response.rb`](actionpack/lib/action_dispatch/http/response.rb), [`content_disposition.rb`](actionpack/lib/action_dispatch/http/content_disposition.rb), [`live_stream_test.rb`](actionpack/test/controller/live_stream_test.rb), [`test_case.rb`](actionpack/lib/action_controller/test_case.rb).

### Current observable path

```text
GET action that calls send_stream(...)
  Live#process
    copy Thread.current keys + IsolatedExecutionState.share_with(except: live_streaming_excluded_keys)
    run action on live thread-pool worker
      send_stream
        start "send_stream.action_controller" with { filename, disposition, type }  # original args
        set Content-Type (symbol Mime | string | extension | "application/octet-stream")
        set Content-Disposition via ContentDisposition.format
        yield response.stream   # first write commits; writeln appends "\n" if missing
        finish notification     # still finishes on exception; payload then has :exception
      ensure response.stream.close   # always; close commits if needed, pushes terminator
    on action exception:
      if already committed: optional HTML completion fragment, on_error, log, close
      else: stash error, re-raise on the waiting request thread after await_commit
    always: commit! (and, on a real worker, nil copied thread locals)
  request thread await_commit, then re-raise pre-commit error if any
```

Buffer write/close/abort:

- First `write` commits, sets `Cache-Control` to `no-cache` unless present, deletes `Content-Length`.
- Producer `close` commits, marks closed, enqueues a terminator.
- Rack `body.close` maps to **abort**, not producer `close`.
- Next `write` after abort: `ignore_disconnect == false` raises `ClientDisconnected`; `true` discards and still returns bytesize.
- Readers must see a terminator or they block forever.

Test-env trap: `ActionController::Live` in `test_case.rb` inlines the worker and skips thread-local cleanup, and sets `Buffer.queue_size = nil`. `LiveStreamTest#setup` restores the real pool. Thread-copy, disconnect, and commit-race checks **must** run with that restore.

### Cross-cutting race-proofing

- `Concurrent::CountDownLatch` for handshakes. Never `sleep` for sync.
- `Timeout.timeout(n) { latch.wait }` and `assert thread.join(n)`. Never unbounded `join`.
- `response.await_commit` before `to_a` / `each` / abort.
- Abort only after the reader has a chunk **and** is blocked again (`Thread.pass until received.any?` then `until reader.status == "sleep"`).
- Simulate disconnect via `to_a` then `body.close` (`RackBody#close` → abort). Do not call `response.stream.close`.
- Always `ensure`: `reader&.kill`; restore `queue_size`, logger, `live_streaming_excluded_keys`, isolation level, IES keys, thread keys.
- Drain or abort every live body so the worker is not left blocked.
- Do not read `response.body` while the producer is blocked on a bounded queue.
- `assert_stream_closed` after a full drain. After abort-without-full-drain, assert `closed?`/`committed?` only; `sent?` requires `Response#each` to finish.

### Checks

#### 1. Inferred content type

`type:` omitted → extension lookup, else `"application/octet-stream"`.

**Seam:** functional `get` of a `send_stream` action.

**Assert:** `"sample.csv"` → String `"text/csv"`; `"export"` → `"application/octet-stream"`; `"notes.CSV"` → `"text/csv"`; unknown ext → octet-stream; stream closed. Existing tests cover csv only.

#### 2. Explicit content type

Symbol uses `Mime[type].to_s`; other truthy values used as-is; beats extension.

**Seam:** existing implicit/explicit/options actions.

**Assert:** `type: :csv` / `"text/csv"` → `"text/csv"`; `type: :json` + `"export"` → `"application/json"`; custom string + `.csv` filename is not overridden.

#### 3. RFC-compatible filename disposition

Header is `ContentDisposition.format` → `#{disposition}; filename="ascii"; filename*=UTF-8''percent-encoded`. Default `"attachment"`.

**Seam:** `response.get_header("Content-Disposition")`. Compare to `ContentDisposition.format(...)` or a full string — **not** `assert_match "attachment"`.

**Assert:** `"my.csv"` → both `filename` and `filename*`; `inline` + `"export"`; non-ASCII (`råcëçâr.csv`) transliterated ASCII + UTF-8 star; non-Latin (`автомобиль.csv`) as in disposition unit tests.

#### 4. Chunk order

Each `write`/`writeln` is one FIFO queue item. Concatenated `body` is not enough.

**Seam:** real worker, `await_commit`, then `each` collecting parts; latch handshake from `test_async_stream`.

**Assert:** two `writeln`s yield `["fruit,quantity\n", "apple,5\n"]`; mixed `write`+`writeln` keeps boundaries; reader asserts `parts.shift == chunk` then counts down.

**Sync:** latches per chunk; `assert t.join(3)`; `ensure` kill reader. Do not overfill `queue_size` (10 in production).

#### 5. Exception before commit

**A.** Live action raises before any write: `assert_raises` on the request thread; no HTML 500 fragment (`Live#process` stash + re-raise).

**B.** Raise inside the `send_stream` block before any `write`: `ensure` still `close`s, and `close` commits, so this is **not** the pre-commit re-raise path. Assert: notification finishes with `:exception`; stream closed; exception logged/surfaced as today.

**Sync:** drain or `assert_stream_closed`; `capture_log_output` with restore. Wrap `get` if it raises.

#### 6. Exception after commit

First `write` commits. Later raise: notification records exception; `ensure` closes; committed-error path may append HTML completion, `on_error`, log.

**Seam:** `send_stream` block that writes once then raises. HTML vs json/event-stream as today.

**Assert:** body prefix is bytes written; HTML ends with streaming completion script; logger has the message; `assert_stream_closed`; `on_error` still runs; notification includes original keys plus `:exception` / `:exception_object`.

#### 7. Client disconnect, `ignore_disconnect: false`

After abort, next `write` raises `ClientDisconnected`. `send_stream` ensure still closes.

**Seam:** write to commit, then more writes; test thread `await_commit`, `to_a`, `body.each { body.close; break }`. Optional bounded-queue fill.

**Assert:** producer hits `ClientDisconnected` (via `on_error`, logger, or rescue latch); discarded writes absent; stream reaches terminal close. Register `on_error` before the failing write.

#### 8. Client disconnect, `ignore_disconnect: true`

Set the flag on the yielded stream, write to commit, abort, further writes discarded, action completes.

**Assert:** latch / `"Work complete"` log; notification **without** `:exception`; stream closed after the block.

**Sync:** `Timeout.timeout(3) { latch.wait }`; `t.join`; restore logger.

#### 9. Stream closure on every path

`send_stream` always `close`s in `ensure`. Double-close is currently non-raising.

**Paths through `send_stream`:** normal return; return without writing; raise before write; raise after write; disconnect ignore false; disconnect ignore true; `on_error` itself raising.

**Assert:** `closed?` on every path; after full drain also `committed?` and `sent?`. Wrap drain in `Timeout`.

#### 10. Copied thread-local state

Worker sees a snapshot of request-thread keys and a dup of IES minus excluded keys. Cleanup nils copied keys on the **worker**, not the request thread.

**Seam:** `LiveStreamTest` restore of `original_new_controller_thread`. Assert **inside** a `send_stream` block.

**Assert:** `:setting` copied; second request after cleanup does not see it; IES/`CurrentState` copied then cleared; same under `isolation_level = :fiber`; excluded `:active_record_connected_to_stack` is absent; request thread’s own `:setting` remains. Drain so cleanup runs before the next test. Do not assert on `clean_up_thread_locals` by name.

#### 11. Notification payload and timing

Name `"send_stream.action_controller"`. Payload `type` is the **argument**, not the resolved Content-Type (`nil` when inferred). Finish runs before `ensure` close. On raise, instrument adds `:exception` then finishes.

**Seam:** `assert_notification` / `capture_notifications` around `get`.

**Assert:** exactly one event; inferred `type: nil` even when header is `"text/csv"`; symbol type stays `:json`; string type stays `"text/csv"`; filename/disposition echo args. Timing: at the last line of the block the stream is **not** yet closed; after `get` it is. Exception in block: same event plus `:exception` / `:exception_object`, still completed. Duration includes writes, not client drain.

**Sync:** `capture_notifications` unsubscribes in `ensure`. Subscribe before `get`.

### Existing coverage vs gaps

| Concern | Existing test | Gap |
|---|---|---|
| Types | `test_send_stream_with_*` | No octet-stream / mixed-case / custom-over-ext |
| Disposition | `assert_match` | Not RFC `filename` + `filename*` exact |
| Chunk order | `test_async_stream`, writeln tests | Not through `send_stream` / not raw chunk array |
| Exception before commit | `test_exception_in_controller_before_streaming` | Not inside `send_stream` before first write |
| Exception after commit | view/callback tests | Not originating in the `send_stream` block |
| Disconnect ignore true | `test_ignore_client_disconnect` | Not via `send_stream` |
| Disconnect ignore false | `test_abort_with_full_buffer` | Buffer overfill, not `send_stream` |
| Close every path | `assert_stream_closed` on several Live paths | Not all `send_stream` error/disconnect paths |
| Thread locals / IES | thread_locals / isolated state tests | Not asserted **inside** a `send_stream` block |
| Notification | `test_send_stream_instrumentation` | Only explicit string type; no timing, inferred `nil`, or exception payload |

`BufferTest` remains the seam for “reader unblocks on abort, including abort-after-close”. Do not re-specify those as `send_stream` checks.

A refactor may split `send_stream` or change pool entry. Keep tests on the keyword API, the yielded stream IO, HTTP headers/chunks, `ClientDisconnected`, the notification name, thread/IES values inside the action, `closed?`/`committed?`/`sent?`, and existing logger strings. Do not assert call counts on private helpers.
