`TimeZone#local` packs wall-clock args into a UTC-constructed `Time` (offset-free carrier), then `TimeWithZone.new(nil, zone, time)` resolves the TZInfo period. Spring gaps raise `PeriodNotFound` and retry after `+1.hour` on that local carrier. Ambiguous times use `period_for_local(..., dst=true)`, then `periods.last` if TZInfo still returns several. `#time` is those (possibly adjusted) local components; `#utc` is that carrier minus `period.observed_utc_offset`. `#<=>` compares only the UTC instant, so `assert_equal Time.utc(...), zone.local(...)` is not a full contract.

#### Failure classes

- Wrong UTC, matching local components → offset/period bug (1, 5, 6, 7)
- Wrong local components, UTC shifted by the same hour → gap retry bug (3, 4)
- Wrong `#dst?`/`#zone` with matching UTC → period metadata bug (5 vs 6: Eastern DST vs Moscow non-DST `periods.last`)
- Pre-1900 local components preserved but `#utc_offset != -37886` → historical LMT lost (7)
