### Observable contract (this revision)

**`#to_plain_text`**
- Returns a non-`html_safe` UTF-8 String.
- Does not mutate the receiver: `#to_html`, fragment source object_id, and attachment `content` attributes stay the same after the call.
- Replaces every `action-text-attachment` node with that attachment’s plain-text representation **before** walking the tree, using `with_full_attributes: false`.
- Builds the replacement `Content` with `canonicalize: false` (so replacements are not minified / gallery-rewritten / raw-markdown-unwrapped).
- Then walks the fragment bottom-up (`BottomUpReducer`) and joins child text.

**Block / line-break markup** (`PlainTextConversion`)
- `p`, `h1`–`h6`: child text, trailing newlines stripped, then `"\n\n"`.
- `div`: child text + `"\n"`.
- `br`: `"\n"`.
- `ul`/`ol`: block (`"\n\n"`) plus an extra leading `"\n"` when nested inside another list.
- `li`: `"#{indent}#{bullet} #{text}\n"`; `•` for `ul` or parentless `li`; `"#{index+1}."` for `ol`; indent is two spaces per extra list depth.
- `blockquote`: wrap first/last non-whitespace in `“` / `”`; whitespace-only → `"“”"`.
- `figcaption`: `"[#{text}]"`.
- `script` / `style`: `""` (inner text dropped). Other unknown elements pass children through (so `<strong>Hello </strong>world!` → `"Hello world!"`).
- Trailing newlines of the whole result are chomped.
- Deep nesting is converted (10_000 levels in the existing test).

**Entities / script-like text**
- Named/numeric entities in text nodes decode: `"<p>asdf &lt; asdf &amp; asdf &gt; asdf</p>"` → `"asdf < asdf & asdf > asdf"`; `"Hello&nbsp;world"` → `"Hello\u00A0world"`; `"&lt;script&gt;alert()&lt;/script&gt;"` → `"<script>alert()</script>"` (not html_safe).
- Real `<script>` / `<style>` elements are omitted: `"<div>safe<script>unsafe</script></div>"` → `"safe"`.
- `#to_plain_text` does **not** run the HTML sanitizer. `onclick` is irrelevant to the string. Sanitization is a `#to_s` / layout concern.

### Checks that `#to_html` / canonical content are not mutated

On every characterization example, and as dedicated tests:

1. `html_before = content.to_html.dup`; `oid = content.fragment.source.object_id`; `content.to_plain_text`; then `assert_equal html_before, content.to_html` and `assert_equal oid, content.fragment.source.object_id`.
2. Same around `content.render_attachments(...) { ... }`: result is a different object; original HTML unchanged.
3. Attachment `content` attribute: original keeps unsanitized value; only the **returned** Content is sanitized / has empty content removed (mirror [`content_test.rb`](actiontext/test/unit/content_test.rb) L182–L203 which today only checks `to_trix_html`).
4. Canonical gallery/minify: `#to_html` still matches [`content_test.rb`](actiontext/test/unit/content_test.rb) L120–L143 (`minifies attachment markup`, gallery unwrap including nested `<blockquote>` and whitespace). `#to_plain_text` must run **after** that canonicalize, not skip it.
5. `render_attachments` must keep `canonicalize: false` on the result — already asserted for markdown tags at [`markdown_conversion_test.rb`](actiontext/test/unit/markdown_conversion_test.rb) L1124–L1136. Add a plain-text analogue: replacement string `"<div>x</div>"` must remain a div in `rendered.to_html`, not be rewritten.
6. Repeat `#to_plain_text` twice; also `#to_html` then `#to_plain_text` then `#to_html` again.

`Fragment#replace` already dups (`fragment.rb` L33–L47). A refactor that walks nodes in place on `source` would fail (1)–(3).
