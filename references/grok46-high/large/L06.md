`Array.wrap` is a three-branch converter on `Array`. Implementation: [`activesupport/lib/active_support/core_ext/array/wrap.rb`](activesupport/lib/active_support/core_ext/array/wrap.rb) lines 39–47, required from [`activesupport/lib/active_support/core_ext/array.rb`](activesupport/lib/active_support/core_ext/array.rb) line 3. Tests: [`activesupport/test/core_ext/array/wrap_test.rb`](activesupport/test/core_ext/array/wrap_test.rb).

```ruby
def self.wrap(object)
  if object.nil?
    []
  elsif object.respond_to?(:to_ary)
    object.to_ary || [object]
  else
    [object]
  end
end
```

```text
Array.wrap(object)
  object.nil?                 → []
  object.respond_to?(:to_ary)
    yes → object.to_ary
            truthy → that value (no Array type check)
            falsy  → [object]
    no  → [object]
```

The comment at wrap.rb:6–10 lists three cases. The body is stricter than “return the `to_ary` result”: a falsy result is discarded by `|| [object]` (wrap.rb:43). `respond_to?(:to_ary)` is the only gate; `method_missing` alone does not pass it.

### Observable results

**`nil`** → `[]`. wrap.rb:8, 12, 40–41; wrap_test.rb:35–37 `test_nil`.

**Actual Array** → the same object (`assert_same`). wrap.rb:13; wrap_test.rb:30–33 `test_array`. `Array` responds to `to_ary` and `Array#to_ary` returns `self`, so the middle branch is identity-preserving.

**Ordinary object / string / struct** → `[object]`. wrap.rb:10, 14, 45; wrap_test.rb:39–41 `test_object`, 43–45 `test_string`, 47–49 `test_string_with_newline`, 65–68 `test_struct`.

**Hash** → `[{foo: :bar}]` (the hash as one element). wrap.rb:26–29. Hash has `to_a`, not `to_ary`, so wrap takes the else branch.

**`to_ary` returns an Array** → that array (`["foo", "bar"]`). wrap.rb:9; wrap_test.rb:7–11 `FakeCollection`, 51–53 `test_object_with_to_ary`.

**`to_ary` returns `nil`** → `[object]`. Does not return nil and does not call `to_a`. wrap.rb:18–20, 43; wrap_test.rb:24–27 `NilToAry`, 70–73 `test_wrap_returns_wrapped_if_to_ary_returns_nil`.

**`to_ary` returns a non-Array** → that value as-is (`:not_an_array`); no exception. wrap.rb:21–22; wrap_test.rb:18–21 `DoubtfulToAry`, 75–77 `test_wrap_does_not_complain_if_to_ary_does_not_return_an_array`.

**Proxy that does not expose the target’s `to_ary`** → `[proxy]`, even if the target has `to_ary`. wrap_test.rb:13–16 `Proxy` (only `method_missing`, no `respond_to_missing?`), 55–58 `test_proxy_object`, 60–63 `test_proxy_to_object_with_to_ary`. `respond_to?(:to_ary)` is false on the proxy, so wrap never forwards to the target.

### Contrast with `Kernel#Array` (only as wrap.rb documents it)

wrap.rb:16–29, plus 37–38 for splat. Three differences:

1. **`to_ary` returns `nil`:** `Kernel#Array` continues to `to_a`. `Array.wrap` immediately returns `[object]`.
2. **`to_ary` returns neither `nil` nor an `Array`:** `Kernel#Array` raises. `Array.wrap` returns that value.
3. **No `to_ary`:** `Array.wrap` never calls `to_a`; it returns `[object]`. Documented hash example: `Array(foo: :bar) # => [[:foo, :bar]]` vs `Array.wrap(foo: :bar) # => [{:foo=>:bar}]`.

The docs also note `[*object]` returns `[]` for `nil` and otherwise calls `Array(object)`, so those `Kernel#Array` differences apply to non-nil objects under splat (wrap.rb:31–38).

I did not inspect MRI’s `Kernel#Array`; the contrast is only what wrap.rb states.
