## Behavior-preservation verification for `ActiveRecord::Base.connected_to_many`

### Derived contract

`connected_to_many` is a **Base-only, block-scoped, multi-class stack push**. It does not swap connections itself. It pushes one hash onto `ActiveRecord::Base.connected_to_stack` and pops it in `ensure`. Role/shard/write-prevention are then resolved by walking that stack.

Source: [`connection_handling.rb`](activerecord/lib/active_record/connection_handling.rb) lines 160–190, 420–439; stack lookup in [`core.rb`](activerecord/lib/active_record/core.rb) lines 160–224.

```ruby
def connected_to_many(*classes, role:, shard: nil, prevent_writes: role == ActiveRecord.reading_role)
  classes = classes.flatten
  if self != Base || classes.include?(Base)
    raise NotImplementedError, "connected_to_many can only be called on ActiveRecord::Base."
  end
  if role == ActiveRecord.reading_role && !prevent_writes
    raise ArgumentError, "cannot set `prevent_writes` to false when `role` is `reading`."
  end
  append_to_connected_to_stack(role: role, shard: shard, prevent_writes: prevent_writes, klasses: classes)
  begin
    yield
  ensure
    connected_to_stack.pop
  end
end
```

Observed rules:

1. **Flattening.** `*classes` then `Array#flatten` (recursive). A single class, several classes, one array, mixed nested arrays, and the existing `[SecondaryBase, TertiaryBase]` form are equivalent after flatten.
2. **Receiver.** `self` must be `ActiveRecord::Base`. Any other receiver raises `NotImplementedError` with `"connected_to_many can only be called on ActiveRecord::Base."` Existing: [`base_test.rb:2106-2109`](activerecord/test/cases/base_test.rb).
3. **No `Base` in the class list.** `classes.include?(Base)` after flatten uses object identity, not subclass. Same `NotImplementedError` / same message. Existing: [`base_test.rb:2112-2115`](activerecord/test/cases/base_test.rb).
4. **Role is required.** `shard` defaults to `nil`. A nil shard is falsy in `current_shard`, so a `connected_to_many` entry **does not override shard** unless `shard:` is passed. Role is always set.
5. **`prevent_writes` default.** `role == ActiveRecord.reading_role` (`:reading` by default). Reading ⇒ true; any other role ⇒ false. Existing: [`base_test.rb:2118-2125`](activerecord/test/cases/base_test.rb).
6. **Hard reject.** `role: :reading, prevent_writes: false` raises `ArgumentError` `"cannot set \`prevent_writes\` to false when \`role\` is \`reading\`."` Existing: [`base_test.rb:2128-2133`](activerecord/test/cases/base_test.rb). Explicit `prevent_writes: true` is legal for reading and writing.
7. **Selection is per connection class.** `current_role` / `current_shard` / `current_preventing_writes` walk the stack newest-first and match `hash[:klasses].include?(connection_class_for_self)` (or `Base`). An unrelated connection class keeps its prior role/shard/prevent_writes. Docstring and [`test_connected_to_many`](activerecord/test/cases/connection_adapters/connection_swapping_nested_test.rb) (lines 453–529).
8. **Nesting.** A newer matching entry wins. `connected_to` pushes `klasses: [self]`; `connected_to_many` pushes `klasses: classes`. They share one stack. Inner pop must restore the outer entry, not the pre-outer state.
9. **Restore on every exit.** `ensure` pops after normal return, `raise`, and `throw`. Invalid calls that raise **before** `append_to_connected_to_stack` must leave the stack unchanged.
10. **Isolation.** The stack is `IsolatedExecutionState[:active_record_connected_to_stack]` ([`core.rb:217-224`](activerecord/lib/active_record/core.rb)). Default isolation is `:thread` ([`isolated_execution_state.rb`](activesupport/lib/active_support/isolated_execution_state.rb)). A sibling thread/fiber must not see another context’s push.
11. **Writes.** `lease_connection.preventing_writes?` is true for replicas **or** when the stack says so ([`abstract_adapter.rb:258-264`](activerecord/lib/active_record/connection_adapters/abstract_adapter.rb)). Actual writes then raise `ActiveRecord::ReadOnlyError` ([`query_intent.rb:426-428`](activerecord/lib/active_record/connection_adapters/query_intent.rb)). To isolate the `prevent_writes` flag from replica behavior, use configs **without** `replica: true` (pattern in `test_prevent_writes_can_be_changed_granularly`).

Check order that leak tests must freeze: flatten → receiver/`Base` check → reading/`prevent_writes` check → `append_to_connected_to_stack` (may raise `ShardSwapProhibitedError`) → `yield` → `ensure` pop. Reordering so a rejected call appends first is a stack leak.
