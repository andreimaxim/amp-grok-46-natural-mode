## Behavior-preservation verification for `ActiveRecord::Base.connected_to_many`

Derived from current source and tests. No implementation changes.

### Derived contract

`connected_to_many` is a **Base-only, block-scoped, multi-class stack push**. It does not swap connections itself. It pushes one hash onto `ActiveRecord::Base.connected_to_stack` and pops it in `ensure`. Role/shard/write-prevention are then resolved by walking that stack.

Source: [`connection_handling.rb`](activerecord/lib/active_record/connection_handling.rb) lines 160–190, 420–439; stack lookup in [`core.rb`](activerecord/lib/active_record/core.rb) lines 160–224.

```ruby
def connected_to_many(*classes, role:, shard: nil, prevent_writes: role == ActiveRecord.reading_role)
  classes = classes.flatten
  if self != Base || classes.include?(Base)
    raise NotImplementedError, "connected_to_many can only be called on ActiveRecord::Base."
  end
  if role == ActiveRecord.reading_role && !prevent_writes
    raise ArgumentError, "cannot set `prevent_writes` to false when `role` is `reading`."
  end
  append_to_connected_to_stack(role: role, shard: shard, prevent_writes: prevent_writes, klasses: classes)
  begin
    yield
  ensure
    connected_to_stack.pop
  end
end
```

Observed rules:

1. **Flattening.** `*classes` then `Array#flatten` (recursive). A single class, several classes, one array, mixed nested arrays, and the existing `[SecondaryBase, TertiaryBase]` form are equivalent after flatten.
2. **Receiver.** `self` must be `ActiveRecord::Base`. Any other receiver raises `NotImplementedError` with `"connected_to_many can only be called on ActiveRecord::Base."` Existing: [`base_test.rb:2106-2109`](activerecord/test/cases/base_test.rb).
3. **No `Base` in the class list.** `classes.include?(Base)` after flatten uses object identity, not subclass. Same `NotImplementedError` / same message. Existing: [`base_test.rb:2112-2115`](activerecord/test/cases/base_test.rb).
4. **Role is required.** `shard` defaults to `nil`. A nil shard is falsy in `current_shard`, so a `connected_to_many` entry **does not override shard** unless `shard:` is passed. Role is always set.
5. **`prevent_writes` default.** `role == ActiveRecord.reading_role` (`:reading` by default). Reading ⇒ true; any other role ⇒ false. Existing: [`base_test.rb:2118-2125`](activerecord/test/cases/base_test.rb).
6. **Hard reject.** `role: :reading, prevent_writes: false` raises `ArgumentError` `"cannot set \`prevent_writes\` to false when \`role\` is \`reading\`."` Existing: [`base_test.rb:2128-2133`](activerecord/test/cases/base_test.rb). Explicit `prevent_writes: true` is legal for reading and writing.
7. **Selection is per connection class.** `current_role` / `current_shard` / `current_preventing_writes` walk the stack newest-first and match `hash[:klasses].include?(connection_class_for_self)` (or `Base`). An unrelated connection class keeps its prior role/shard/prevent_writes. Docstring and [`test_connected_to_many`](activerecord/test/cases/connection_adapters/connection_swapping_nested_test.rb) (lines 453–529).
8. **Nesting.** A newer matching entry wins. `connected_to` pushes `klasses: [self]`; `connected_to_many` pushes `klasses: classes`. They share one stack. Inner pop must restore the outer entry, not the pre-outer state.
9. **Restore on every exit.** `ensure` pops after normal return, `raise`, and `throw`. Invalid calls that raise **before** `append_to_connected_to_stack` must leave the stack unchanged.
10. **Isolation.** The stack is `IsolatedExecutionState[:active_record_connected_to_stack]` ([`core.rb:217-224`](activerecord/lib/active_record/core.rb)). Default isolation is `:thread` ([`isolated_execution_state.rb`](activesupport/lib/active_support/isolated_execution_state.rb)). A sibling thread/fiber must not see another context’s push.
11. **Writes.** `lease_connection.preventing_writes?` is true for replicas **or** when the stack says so ([`abstract_adapter.rb:258-264`](activerecord/lib/active_record/connection_adapters/abstract_adapter.rb)). Actual writes then raise `ActiveRecord::ReadOnlyError` ([`query_intent.rb:426-428`](activerecord/lib/active_record/connection_adapters/query_intent.rb)). To isolate the `prevent_writes` flag from replica behavior, use configs **without** `replica: true` (pattern in `test_prevent_writes_can_be_changed_granularly`).

Check order that leak tests must freeze: flatten → receiver/`Base` check → reading/`prevent_writes` check → `append_to_connected_to_stack` (may raise `ShardSwapProhibitedError`) → `yield` → `ensure` pop. Reordering so a rejected call appends first is a stack leak.

### Observables and instrumentation (use everywhere)

Snapshot **before** the call, **inside** the block, **after** every exit.

- **Stack (leak detector):** `before = ActiveRecord::Base.connected_to_stack.dup` (dup; the stack is mutated in place). After: `assert_equal before, ActiveRecord::Base.connected_to_stack` and `assert_equal before.size, ActiveRecord::Base.connected_to_stack.size`. Inside a successful call, `size == before.size + 1` and `last` is `{ role:, shard:, prevent_writes:, klasses: }`.
- **Role/shard:** `Model.current_role`, `Model.current_shard`, `Model.connected_to?(role:, shard:)`.
- **Which DB:** `Model.connection_pool.db_config.name` (established pattern in `test_connected_to_many`).
- **Write flag:** `Model.current_preventing_writes` and `Model.lease_connection.preventing_writes?`. Prefer the former when the pool is a replica; use the latter plus a real write when the pool is not a replica.
- **Accidental write:** `assert_raises(ActiveRecord::ReadOnlyError) { record.update_column(...) or INSERT }` and `assert_match /Write query attempted while in readonly mode/, error.message` ([`base_prevent_writes_test.rb:9-16`](activerecord/test/cases/base_prevent_writes_test.rb)). On a class **not** in `klasses`, the same write must succeed.
- **Restore after non-local exit:** `assert_raises` / `assert_throws` around the call, then compare the stack snapshot and each class’s role/shard/prevent_writes to the pre-call values.

Do **not** assert on private helper names. Assert on stack contents, current_*, `db_config.name`, and `ReadOnlyError`.

### Focused test matrix

Reuse `FirstAbstractClass` / `SecondAbstractClass` from [`base_test.rb:37-53`](activerecord/test/cases/base_test.rb) for argument/error cases. Reuse `PrimaryBase` / `SecondaryBase` / `TertiaryBase` plus the sqlite config from `test_connected_to_many` for role/shard/unrelated-model cases. Guard those with `unless in_memory_db?`.

#### 1. Flattening class arguments

**T1a — splat, one class.** Already exists (`base_test.rb:2136`). Keep.

**T1b — splat, two classes.** Already exists (`base_test.rb:2143`). Keep.

**T1c — single nested array.** Already exists via `connected_to_many([SecondaryBase, TertiaryBase], ...)`. Keep.

**T1d — mixed nested arrays (missing).**  
`connected_to_many([SecondaryBase], [[TertiaryBase]], role: :reading)`.  
Inside: both `connected_to?(role: :reading)`; `klasses` on `stack.last` equals `[SecondaryBase, TertiaryBase]` (flatten is recursive). Primary/Base unchanged. After: stack restored.

**Detects:** a refactor that stops flattening, flattens only one level, or wraps classes in an extra array so `include?(connection_class_for_self)` never matches.

#### 2. Role and shard for two independent classes; unrelated model stays

**T2 — two targets + one bystander, role and shard (missing shard today).**  
Setup as `test_connected_to_many`. Outer `ActiveRecord::Base.connected_to(role: :writing, shard: :default)`. Then:

`connected_to_many([SecondaryBase, TertiaryBase], role: :reading, shard: :shard_one)`.

| Class | Inside | After |
|---|---|---|
| SecondaryBase | `secondary_shard_one_replica`, role `:reading`, shard `:shard_one`, prevent_writes true | `secondary`, writing, default |
| TertiaryBase | `tertiary_shard_one_replica`, same | `tertiary`, writing, default |
| PrimaryBase (unrelated) | still `primary`, writing, default, prevent_writes false | unchanged |

Also assert `PrimaryBase.lease_connection` object/pool name does not change across the inner call.

**T2b — role only, shard left alone (missing).**  
Outer: Primary reading `shard_one`, Secondary writing default (pattern from `test_roles_and_shards_can_be_swapped_granularly`). Inner: `connected_to_many([SecondaryBase], role: :reading)` with **no** `shard:`. Secondary becomes reading **on default**, not `shard_one`. Primary still reading `shard_one`.

**Detects:** global `connected_to` substitution; applying the entry to `Base`; treating nil shard as `:default` and yanking an unrelated class onto that shard.

#### 3. Default and explicit `prevent_writes`

**T3a — default reading ⇒ prevent writes, bystander not.** Exists (`base_test.rb:2118`). Strengthen with a real write if the pool is not a replica: target `INSERT` raises `ReadOnlyError`; `ActiveRecord::Base` / Primary write succeeds.

**T3b — default writing ⇒ writes allowed (missing).**  
`connected_to_many([SecondaryBase], role: :writing)` after an outer reading context that applied to Secondary. Inside: `current_preventing_writes` false; an `INSERT` on Secondary succeeds. Primary still whatever it was.

**T3c — explicit `prevent_writes: true` on writing (missing, high value).**  
Configs **without** `replica: true`. `connected_to_many([SecondaryBase], role: :writing, prevent_writes: true)`.  
Inside: `SecondaryBase.current_preventing_writes == true`, `db_config.name` still the **writer** (`secondary`, not replica), `ReadOnlyError` on Secondary write, Primary write succeeds. After: flags restored.

**T3d — explicit `prevent_writes: true` on reading.** Same as default; still assert the flag and `ReadOnlyError`. Guards a refactor that only honors the default expression.

**Detects:** `prevent_writes` applied to every class; writes allowed on a reading target; `prevent_writes: true` accidentally switching to a replica (role/pool vs flag confusion).

#### 4. Reject `role: :reading, prevent_writes: false`

**T4.** Exists (`base_test.rb:2128`). Add:

- stack snapshot unchanged (no append-then-raise leak);
- same rejection after flatten (`connected_to_many([[SecondAbstractClass]], role: :reading, prevent_writes: false)`);
- `prevent_writes: false` **is** legal with `role: :writing`.

**Detects:** check moved after push; check using the default instead of the passed value; flatten skipped so the class list never validates.

#### 5. Non-Base receiver

**T5.** Exists (`base_test.rb:2106`). Add: no block required (today it raises before `yield`); stack unchanged; also try `PrimaryBase.connected_to_many(...)` in the swapping fixture. Message stays `"connected_to_many can only be called on ActiveRecord::Base."`

**Detects:** allowing abstract connection classes the way `connected_to` does; leaking a stack entry on the error path.

#### 6. Inclusion of `ActiveRecord::Base`

**T6a.** Exists (`base_test.rb:2112`). Add stack-unchanged.

**T6b — Base nested in flattened args (missing).**  
`connected_to_many([SecondAbstractClass, [ActiveRecord::Base]], role: :writing)` raises the same `NotImplementedError`, stack unchanged.

**T6c — subclass of Base is allowed.** `ApplicationRecord` or `PrimaryBase` in the list must **not** hit this error (`include?(Base)` is identity). Already implied by `test_connected_to_many`.

**Detects:** `<= Base` / `is_a?` instead of `include?(Base)`; flatten skipped so nested Base is missed; stack push before the check.

#### 7. Nesting with `connected_to`

**T7a — `connected_to` wrapping `connected_to_many`.** Exists as `test_connected_to_many`. Keep. Assert inner pop restores the **outer `connected_to`**, not the pre-outer state.

**T7b — `connected_to_many` wrapping `connected_to` (missing).**  
`connected_to_many([SecondaryBase, TertiaryBase], role: :reading)` then `SecondaryBase.connected_to(role: :writing)` (or with shard). Inside inner: Secondary writing, Tertiary still reading, Primary untouched. After inner: both reading. After outer: all writing default.

**T7c — inner `connected_to_many` overrides one class.** Exists (Tertiary switched back to writing while Secondary stays reading). Keep.

**Detects:** one shared stack vs a side table; pop popping too many frames; `connected_to` entries hiding `connected_to_many` klasses or the reverse.

#### 8. Restore after return, raise, and throw

All three start from the same snapshot of stack + `current_role/shard/prevent_writes` on Primary/Secondary/Tertiary.

**T8a — normal return.** Exists at the end of `test_connected_to_many`. Also assert the block’s return value is the `yield` result (`ensure` without an else still returns yield). Low priority vs leaks.

**T8b — `raise` (missing).**  
Inside the block, `raise RuntimeError, "boom"`. `assert_raises` that error. After: stack and all three classes match the pre-call snapshot. Especially: Secondary/Tertiary must not stay on reading/shard_one.

**T8c — `throw` (missing, no current test).**  
`catch(:done) { connected_to_many(...) { throw :done } }`. Same restore assertions as T8b. `ensure` must run for `throw`; a `rescue`-only restore would fail here.

**Detects:** pop only on the success path; `rescue` without `ensure`; double-pop; leaving `prevent_writes` true on a writer after an exception (accidental-write window).

#### 9. Isolation across concurrent execution contexts

Pattern: [`database_selector_test.rb:219-257`](activerecord/test/cases/database_selector_test.rb) (threads). Fiber only if the harness sets `ActiveSupport::IsolatedExecutionState.isolation_level = :fiber` ([`connection_pool_test.rb:1797-1807`](activerecord/test/cases/connection_pool_test.rb)). Default is `:thread`; under `:thread`, a new Fiber in the same thread **shares** the stack — do not treat that as a bug.

**T9a — sibling thread (required).**  
Parent: `connected_to_many([SecondaryBase, TertiaryBase], role: :reading, shard: :shard_one, prevent_writes: true)` and wait on an `Event`. Child `Thread.new` (no `share_with`): Secondary/Tertiary/Primary still writing default, `current_preventing_writes` false, child `connected_to_stack` empty or equal to its own baseline. Child `INSERT` on Secondary succeeds while parent would raise `ReadOnlyError`. Parent still reading after the child joins.

**T9b — child thread nested call does not corrupt parent.**  
Child runs its own `connected_to_many([PrimaryBase], role: :reading)`. Parent’s Secondary/Tertiary stay as in T9a; parent Primary stays writing. After both exit, parent stack restored.

**T9c — fiber, only when `isolation_level == :fiber`.** Same as T9a with `Fiber.new`. Skip or no-op when isolation is `:thread`.

**Detects:** a process-global stack; mutating `Thread.current` instead of `IsolatedExecutionState`; child writes seeing the parent’s `prevent_writes`.

### Priority (leaked role/shard and accidental writes first)

Run these first after a refactor:

1. **T8b / T8c** — raise/throw restore (leaked reading role or `prevent_writes` after failure).
2. **T4 / T5 / T6** — rejected calls leave stack size unchanged.
3. **T3c / T3a** — `ReadOnlyError` on the targeted class only; bystander still writes.
4. **T2 / T2b** — two-class role+shard; nil shard does not move bystanders.
5. **T9a** — parent prevent_writes must not appear in a sibling thread.
6. **T7b** — inner `connected_to` pop must not drop the outer `connected_to_many` frame.
7. Flatten / receiver / Base-inclusion — contract, but they fail loudly if stack leaks are already covered.
