- Next `data_source_exists?("courses")`: **1** (name-specific lookup, **not** a full re-list, because `@data_sources` is non-empty). Existing test at line 288.
- Next `columns("courses")`: **1**.

**Catches stale entries:** after `clear_data_source_cache!("courses")`, `columns`/`primary_keys`/`indexes` must miss and re-query. If a refactor leaves the row in any hash, `cached?` stays true or `assert_queries_count(1)` fails (0 queries = stale hit). After `clear!`, `size` must be 0 even though indexes are not part of `size` (indexes hash must be empty too; assert `@indexes` empty or `indexes` re-queries).

### 3. Nonexistent tables (`"omgponies"`)

| Accessor | First (SQLite) | Repeat | Result | Stored? |
|---|---|---|---|---|
| `data_source_exists?` | **2** (full list + name lookup) | **0** | `false` | yes (`false`) |
| `primary_keys` | **2** | **0** | `nil` | **no** (`fetch` miss every time; existence cache makes repeat free) |
| `indexes` | **2** | **0** | `[]` | **no** (else branch returns `[]` without writing `@indexes`) |
| `columns` / `columns_hash` | **1** | **1** (not cached) | `ActiveRecord::StatementInvalid` | **no** |

`add("omgponies")`: **2** queries, does not populate columns/PK/indexes; does populate `@data_sources` including `"omgponies" => false`.

**Catches extra round trips:** repeat `data_source_exists?`/`primary_keys`/`indexes` must be 0. Repeat `columns` **must still query** (1) and raise — caching a miss would be a behavior change. Do not assert `@indexes["omgponies"]` or `@primary_keys["omgponies"]` exist.

### 4. Composite and missing primary keys

- `"courses_professors"` (join, `id: false`): `primary_keys` → `nil`, stored as `nil`; first **2** (or **1** if list already cached), repeat **0**. `add_all` must cache this nil (`test_add_all_caches_a_table_without_a_primary_key`).
- Composite: `create_table(..., primary_key: [:one, :two])`. Lazy `primary_keys` and `add_all` both return `["one", "two"]` (array, not joined string). Lazy first count **2** on SQLite. Drop the table in `ensure`.

`connection.primary_key` (singular) vs bulk `connection.primary_keys(tables)`: both must collapse `size > 1` to the array and `size <= 1` to the single name or `nil`.

### 5. Schema-ignored tables (string and regexp)

`ActiveRecord.with(schema_ignored_tables: ["professors"])` and `[/^profess/]` (plus deprecated `schema_cache_ignored_tables`). Predicate is `ignored === table_name`.

Live cache, **0 queries**, no catalog hit:

- `data_source_exists?("professors")` → **`nil`** (not `false`)
- `columns` / `columns_hash` → `StatementInvalid` (`"Table 'professors' doesn't exist"`)
- `primary_keys` → `nil`
- `indexes` → `[]`

`data_source_exists?("courses")` still lists tables but **omits** professors: `@data_sources.keys` are `colleges, courses, courses_professors, dogs` only.

Dump then load (existing `assert_professors_ignored`): Marshal `.dump` under the ignore list; reload; courses fully cached with **0** queries; professors still `nil` / raise / `[]` as above; dumped `@data_sources` must not contain `"professors"`.

**Catches stale entries:** a dump built while ignoring professors must not later answer `columns("professors")` from cache. A live `data_source_exists?` that returns `false` instead of `nil` is a behavior change.

### 6. Duplicate-cache independence

`initialize_dup` dups the five hashes, not the values.

- `c1.columns("courses")`; `c2 = c1.dup`; `c2.clear_data_source_cache!(..., "courses")`.
- `c1.columns("courses")` → **0** (still cached).
- `c2.columns("courses")` → first-access count (**1** on SQLite).
- Reverse: populate `columns` only on the dup; orig must still query.

Also: `c1.instance_variable_get(:@columns).object_id != c2.instance_variable_get(:@columns).object_id`. Shared inner Column objects are expected (dedup); shared **hashes** are a bug (clearing one would stale-clear the other).

### 7. Frozen / deduplicated cached values

`deep_deduplicate` intern-freezes `String` and `Deduplicable` (`Column`, `SqlTypeMetadata`, PG/MySQL type metadata). `IndexDefinition` is **not** Deduplicable.

After lazy populate:

- Column **objects** frozen; column **names** frozen; `columns` **array** not frozen.
- `columns_hash` **frozen**; keys frozen.
- PK string frozen (`"id"`).
- Index names frozen; index objects / indexes array **not** frozen.

Two independently filled caches: `cols1.first.equal?(cols2.first)` (same interned Column) and same interned `sql_type_metadata`.

YAML `init_with` without `"deduplicated"` re-derives `@columns_hash` from `@columns` and re-deduplicates. With `"deduplicated" => true`, skip that path: `assert_same coder["columns"], cache.instance_variable_get(:@columns)` (existing test).

`Marshal.load(..., freeze: true)` on `.dump` files freezes the columns array as well.

`encode_with` does **not** emit `columns_hash` or `deduplicated`; keys of `columns`, `primary_keys`, `data_sources`, `indexes` are `sort.to_h`. Unsorted keys fail `test "#encode_with sorts members"` and break gzip MD5 identity.

### 8. YAML / Marshal dump-load, gzip, older dumps

Keep `DumpAndLoadTests` for `.yml` and `.dump`, plain and `.gz`. After `dump_to` + `load!` (version matches):

```
assert_no_queries(include_schema: true) do
  assert_equal 3, cache.columns("courses").size
  assert_equal 3, cache.columns("courses").map { |c| c.cast_type }.compact.size
  assert_equal 3, cache.columns_hash("courses").size
  assert cache.data_source_exists?("courses")
  assert_equal "id", cache.primary_keys("courses")
  assert_equal 1, cache.indexes("courses").size
end
```

Gzip path: `Zlib::GzipReader` + format `load`, **and** `load_bound_reflection` — both **0** schema queries. `open` sets `zipper.mtime = 0`; two dumps 1s apart must have equal MD5 (`test_gzip_dumps_identical`). `dump_to` on an empty reflection populates via `add_all` first (`size` 0 → 20 on arunit2 / 5 tables × 4 size components).

**5.1 YAML** (`activerecord/test/assets/schema_dump_5_1.yml`): has `columns_hash`, **no** `indexes` key.

- `columns("posts")` size 11, `columns_hash` 11, `data_source_exists?` true, `primary_keys` `"id"` → **0** queries.
- `indexes("courses")` → **must query** (`assert_queries_count(include_schema: true)` ≥ 1; SQLite **3** because `@data_sources` is the 5.1 posts DB list, so `"courses"` is a miss + name lookup + 2 index queries). Repeat indexes → **0**.
- `init_with` sets `@indexes = coder["indexes"] || {}`.

**Older Marshal** without indexes (5-element array): `marshal_load` sets `@indexes ||= {}` and rebuilds `@columns_hash` from `@columns` via `index_by(&:name)`. `columns_hash` → **0** queries; `indexes` → catalog queries then **0**. A 7-element payload’s trailing `database_version` is ignored.

`marshal_dump` shape: `[@version, @columns, {}, @primary_keys, @data_sources, @indexes]` — the third slot is always `{}`.

`_load_from`: filename including `.dump` → `Marshal.load`; else `YAML.unsafe_load`; `.gz` → `Zlib::GzipReader`.

### 9. Schema version and `check_schema_cache_dump_version`

Default `SchemaReflection.check_schema_cache_dump_version = true`, `use_schema_cache_dump = true`.

- Matching dump: `load!` may query current `schema_version` once; after that the five accessors are **0**.
- Mismatched dump (`version: 999`): warn `Ignoring <path> because it has expired. The current schema version is X, but the one in the schema cache file is 999.`; `load!` uses empty cache; `size == 0`; next `columns("courses")` is a cold-cache query (**1** on SQLite). That is the assertion that catches **using stale dump entries**.
- `ActiveRecordError` during version check: warn `Failed to validate the schema cache because of ...` and skip the dump (same empty cache).
- `cached?` with check **on** and `@cache` nil: **does not** load the file (would need a connection); returns nil/false without queries.
- `SchemaReflection.with(check_schema_cache_dump_version: false)`: `cached?("courses")` is true with **0** queries and **no** pool (`BoundSchemaReflection.new(reflection, :__unused_pool__)`). A dump with `version: 999` is **used as-is**: `load!` **0** queries, `columns` **0** queries, `version` reports **999**. That is the preserved “stale dump is trusted” behavior when checking is disabled.

`lazily_load_schema_cache` (skipped on in-memory SQLite): cache ivar nil until access / `verify!`; not required for the accessor matrix above.

### 10. Adapter portability boundaries

Pin exact first-access integers only on SQLite. On MySQL/Trilogy/PostgreSQL, pin **repeat = 0** and **after-`add` = 0**; treat first-access as “a constant few catalog queries, not one per table”.

| Work | SQLite3 | MySQL / Trilogy | PostgreSQL |
|---|---|---|---|
| `data_sources` / empty-cache `data_source_exists?` | 1× `pragma_table_list` | 1× `information_schema` / `SHOW TABLES` equivalent | 1× `pg_class`/`data_source_sql` |
| `columns` | 1× `table_structures` | 1× `information_schema.columns`; fallback `SHOW FULL FIELDS` per empty table | 1× `pg_attribute` batch; fallback `column_definitions` per empty table |
| `indexes` | **2** (`index_list` + `index_info`) | 1× `information_schema.statistics` | 1× `pg_index` |
| `primary_keys` | 1× `table_structures` (same CTE as columns; **not shared** with a prior `columns` call — `add` issues both) | 1× PK catalog | 1× `pg_index` PK query |
| `version` | `schema_migrations` existence | adapter `schema_version` | adapter `schema_version` |
| Qualified `schema.table` | N/A | `fetch_by_schema` → one query **per schema group** | same |
| 5.1 dump `indexes` | queries (count adapter-specific) | queries | queries |
| Repeat / post-`add` / successful dump-load | **0** on all | **0** | **0** |
| Ignored-table short-circuit | 0, return `nil` | 0, `nil` | 0, `nil` |
| Missing `columns` | raise, uncached, queries every time | same | same |

Do not assert SQLite’s 5-query `add` or 3-query `indexes` on PG/MySQL. Do assert `assert_no_queries(include_schema: true)` on repeat everywhere. If an adapter’s bulk reader is O(tables), that is existing adapter behavior (`schema_statements_test.rb` skips when every table is read one-at-a-time); SchemaCache must not add a **second** bulk read on repeat.

### Assertions that catch extra round trips or stale entries

1. Repeat of each of the five accessors: `assert_no_queries(include_schema: true)`.
2. After `add(table)`: all five **0**; second `add` **0**.
3. After successful YAML/Marshal/gzip load with matching version: all five **0**, including `cast_type` present on columns.
4. 5.1 dump: four accessors **0**; `indexes` **≥ 1** then **0**. Failure to query indexes means a phantom empty `@indexes` was written.
5. Expired dump with check on: `size == 0` and `columns` queries; if `columns` is 0, stale dump entries leaked.
6. Check off + expired dump: `columns` **0** and `version == 999`; if it queries, version skipping regressed.
7. `clear_data_source_cache!(name)` then `data_source_exists?(name)` is exactly **1** (not 0 = stale data_source; not a full re-list unless `@data_sources` was emptied).
8. `clear!` then `size == 0` and next accessor is a cold hit.
9. Dup independence: clearing/populating one cache does not change the other’s query count.
10. Ignored dump: `data_source_exists?("professors")` is `nil` with **0** queries after load; `true` or a catalog query is a stale/leaked entry.
11. Missing `columns` raises **and** still queries on the second call.
12. `encode_with` key order stable; gzip MD5 identical — instability is a dump-behavior change, not just cosmetics.

Existing tests in `schema_cache_test.rb` remain the regression net; the counts above are the additional pins a refactor must not move except where an adapter’s catalog SQL is documented to differ.
