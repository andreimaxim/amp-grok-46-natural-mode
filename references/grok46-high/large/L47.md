A refactor of Railties autoload-path assembly can only be called behavior-preserving if loader ownership, constant identity/removal, `$LOAD_PATH` membership, freeze errors, reloader callbacks, and boot/reload errors stay the same. Treat `all_*` concatenation, `@_all_autoload_paths` memoization, and full Zeitwerk `dirs` order as private.

### What is actually observable

Assembly is custom arrays plus existent `Rails::Paths` directories, then per engine:

- main roots = `(autoload + eager − once).uniq`
- once roots = `once.uniq`
- eager roots merge into a `Set`

`String` vs `Pathname` is type-sensitive under `Array#-` / `uniq`. Engine `set_load_path` / `set_autoload_paths` / `set_eager_load_paths` run before `:bootstrap_hook`, `unshift` into `ActiveSupport::Dependencies`, then freeze that engine’s config arrays. `once` is set up (and its global array frozen) before `:bootstrap_hook`, so later initializers can autoload from it. `main` is set up in the finisher (global autoload array frozen then). `Dependencies.clear` reloads **main only**. `$LOAD_PATH` always gets `lib`; other autoload dirs join it only if `config.add_autoload_paths_to_load_path` (false since 7.1 defaults).

### Invariants to keep

| Contract | Exact assertion |
|---|---|
| Eager-only dir is a **main** root | dir ∈ `main.dirs`, ∉ `once.dirs`; constant autoloads |
| Once subtracts from main even if also eager | dir ∈ `once.dirs`, ∉ `main.dirs`; `Dependencies.eager_load?(dir)` |
| Once+eager | production defines constant at boot; after `reloader.reload!`, `object_id` unchanged; file side-effect runs once |
| Once, not eager | production: `const_defined?` false until referenced |
| Duplicates | path appears **once** in `main.dirs` / `once.dirs` |
| Missing custom dir | stays in `Dependencies.*`, not in loader `dirs` |
| Flag false | `app/models` ∉ `$LOAD_PATH`; `require "user"` → `LoadError`; `User` still autoloads; `lib` remains on `$LOAD_PATH` |
| Freeze | after boot, `<<` on config and both `Dependencies` arrays → `FrozenError`; once still autoloads from initializers after bootstrap |
| Reload | main constant identity changes on edit, `NameError` after delete; once identity survives; `watchable_args` is `main.dirs` only |
| Production eager | app + engine + once+eager loaded at boot; once-not-eager not |
| Isolated engine vs app | `Post.origin` vs `Blog::Post.origin`; both roots ∈ `main.dirs` |
| `to_prepare` | user callback count +1 on boot, +1 per `reload!` — not internal list size |

Do **not** `assert_equal` full `app/*` listings, TSort initializer order, or entire `autoloaders.*.dirs`.

### New black-box probes

Isolation apps, membership/identity/errors only:

1. **Duplicates/overlap** — same path twice on `autoload_paths`; path on both autoload and once (once wins, not reloaded).
2. **Eager ∩ once** — identity stable across `reload!`; not in `main.dirs`.
3. **Flag false** — `$LOAD_PATH` membership, `LoadError` vs Zeitwerk success, `lib` exception.
4. **Dev reload** — edit changes `User.object_id` and method body; delete → `NameError`; once-path edit ignored; extras ∉ `watchable_args`.
5. **Production eager** — side-effect flags for app/engine/once+eager; once-not-eager lazy; `main` not reloading.
6. **Isolated engine vs app** — both constants; both roots; engine once-path survives reload.
7. **Freeze** — `FrozenError` post-boot; initializer before `:setup_main_autoloader` can still append to `Dependencies.autoload_paths`.
8. **Callbacks** — user `to_prepare` count; existing spy that `Dependencies.clear` reloads main only.

Engine-vs-app winner for a **colliding non-isolated** constant is unshift/TSort order — don’t probe collisions; probe isolated namespaces.
