`Array#excluding` (aliased as `without`) returns a new array via `self - elements.flatten(1)`, so both splat args (`.excluding(3, 5)`) and a one-level wrapping array (`.excluding([3, 5])`) are treated the same. Nested arrays in the receiver are compared as whole elements after that single flatten, so `[[0, 1], [1, 0]].excluding([[1, 0]])` yields `[[0, 1]]` rather than descending into inner arrays. `Array#-` removes every occurrence of each excluded value while leaving other duplicates in the receiver intact. The receiver is not mutated.
